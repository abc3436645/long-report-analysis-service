# ADR 0024：授信决策论证与五项独立审阅

状态：已接受（2026-11-04，用户授权按全局优化建议实施）。

## 1. 问题与决定

原有C08全面分析、逐章表达审查和来源门禁不足以保证具体授信事项的论证。C09将现金创造、到期偿还、风险条件及剩余风险作为主线；C08保留优势潜力与风险的分析内容，其综合评价统领全文的目标层级被替代。遵从C02/C03/Q42/Q44/Q46/Q47，不重建额度或评级模型，不自动批准授信。

## 2. 最小实现

financial_due_diligence升级0.3.4，writing_guidance.credit_decision规定五项分析成果及条件分类、三层输出。保持固定九章、原证据生命周期及Word批注。

quality.decision_reviews声明五项id/criteria，由既有review_requirements生成decision:<id>，复用claim定位和证据校验。场景加载校验唯一id、非空criteria。build、review submit及validate沿用同一入口，缺少记录拒绝通过。无此配置的冻结项目保持原契约；不改写历史项目和报告。

不做关键词裁决、自动风险分类或默认压力阈值。计算和格式沿用已有确定性机制；专业审阅负责核对假设、资金匹配、条件可执行性与剩余风险。记录齐备不代表内容合格。

## 3. 验收与限制

回归覆盖缺任一决策项、失效引用、错误定位、非法配置和旧配置兼容，并由现有CLI生命周期测试验证要求传递及发布门禁。真实案例底稿需明确未核事项；新完整报告和业务签认单独记录，不以配置加载或合成测试冒充。

业务细则见[场景规格第21节](../scenarios/财务公司授信评审-场景规格.md#21-授信决策论证与条件闭环2026-11-04)，来源决策见[访谈记录C09](../架构细化-决策树与访谈记录.md#20-授信决策论证c09已确认)。

金额展示补充：`presentation.amount_display.table_grouping`为可选布尔值，0.3.4启用表内千分位；仅作用于表内金额最终展示，正文、图形数值与冻结事实不变。缺省关闭保持旧配置兼容，非布尔值拒绝加载。
