# 财务尽调逐页取证与确定性比率及审阅覆盖

## 1. 决策依据

2026-10-30用户确认Comet修复范围，并指定gpt-6.1-sol medium与gpt-6.1-terra medium真实对比。原DeepSeek两稿暴露可读材料漏用、数值量级错误、合并与单体混用、固定结构绕过和审阅缺少覆盖记录等问题，见[差异审查](../scenarios/财务公司授信评审-江铜华北双模型差异审查.md)。沿用C02/C03的外部额度评级职责、C08综合评价、Q42允许带缺口完整交付和Q44/Q46/Q47的核对与策略边界。

## 2. 决策

财务场景升级为0.3.0，以配置financial_quality启用新门禁，analysis.financial_metrics登记固定描述性算子。旧项目继续使用原冻结配置；不自动改写或升级历史项目。模板文件仍沿用原版资源，固定目录、仿宋及封面规则不变。

PDF保留每个物理页的文本提取覆盖；财务场景允许无文本PDF和JPG/PNG归档，未核页公开进入上下文和缺口。派生材料关联已归档原件哈希及全量定位映射，系统验证关系存在性，OCR内容与单位语义仍需核读。相同字节已按另一种格式归档时显式拒绝复用，避免TXT行定位被误用于CSV单元格；不同衍生关系不能静默覆盖。稀疏XLSX按实际加载的单元格读取，避免样式污染造成百万行空单元格实例化；局部使用openpyxl稀疏存储并由真实材料及大行号用例回归约束。

两份真实首稿均出现长段OCR引用残留，因此候选提取允许source_span精确子串；程序校验原定位、完整source_value及字符区间与value一致，原文全文留痕，减少整段文字被迫写入报告。该操作只作确定性裁剪，不替代语义核读或金额归一。

财务比率在独立的小模块中按当前冻结事实计算；原始字段用fin.前缀，按subject_id、period、period_start、period_days、financial_scope及financial_version分组。单位明确转换，平均余额用期初期末，结果不年化；分母零、缺基期或范围不明返回状态。金额及比率由程序计算，额度与评级仍只接收外部结果。不存在统一风险阈值或依据缺失时的默认期限。

财务计划逐材料声明用途。章节的表内数值和正文派生值均绑定事实或计算，基本表须呈现或具名披露缺口。outline.planning_guidance中旧“不是新增机械门禁”的说明改为0.3.0条件规则；固定sections及工商股权表结构不变，旧冻结项目沿用原约束。机械审阅记录绑定草稿哈希，覆盖固定小节、融资章、实际表格和四类重要结论；真实独立审阅者作内容判断。异名ID、覆盖齐备和哈希一致均不证明语义正确或业务批准。

## 3. 结果与限制

增加material_disposition、analysis_material_coverage、financial_binding、financial_review_coverage和candidate_integrity校验。编译后的草稿与原始章节正文哈希绑定，手工修改交付或原始章节后不能继续发布旧审阅结果。新要求通过同一CLI生命周期执行，不将渲染器当发布入口。真实发布发现多余空行下渲染器与Word标题回读的解析不一致，局部统一strip处理；回归同时验证空行不误阻断、真实标题改动仍拒绝。

全无文本不等于业务文件未提供；有文本不等于全文核验；衍生物不等于原件语义正确；机械门禁不等于独立性证明。本决策不新增通用OCR平台、模型厂商适配器或授信审批功能。实验字体例外须显式披露，不改变正式字体门禁。
