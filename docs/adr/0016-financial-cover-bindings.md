# 财务公司尽调封面按对象额度和运行日期生成

2026-10-30补充：[ADR 0018](0018-financial-amount-display.md)将声明`amount_display`的新配置封面额度改为按正文金额分级选择单位。下文固定亿元展示保留为原决策记录；其余绑定和核验约束继续适用。

用户要求财务公司尽调封面除标题外包含呈报部门、客户经理及当日时间，并再次明确仅作用于该场景。用户文字中的“承包时间”按其示例解释为“呈报时间”；没有新增合同或承包业务字段。

`financial_due_diligence/scenario.yaml.presentation.cover`定义标题模板、额度选择器、显示单位、缺口文字、时区及有序展示字段。标题为“关于{business_unit}{credit_amount}综合授信调查报告”；业务公司取项目`subject_scope.business_unit`，不预填样本公司。呈报部门读取`report_metadata.prepared_by`、客户经理读取`report_metadata.account_manager`，缺省均为`XXXX`。呈报时间取服务器持久化的本轮`started_at`，按Asia/Shanghai转为年月日，不接受用户日期覆盖，不用评价基准、材料日期或稍后的发布时间替代。每个新运行均独立记时，同一已发布运行重试保持原结果。

标题额度当前按已声明的实施默认绑定`application_credit_amount`选择器（application来源、credit_amount字段），表示本次申请额度；这不是用户对“申请／最终授信结果”的额外业务确认，也不替代外部授信模型结果。宿主须将与本次主体及评价基准相符的事实核验并封存。仅使用本轮冻结事实，唯一、数值和单位可核验时确定性换算为配置的亿元显示；不按上传顺序选冲突值。单位仅支持元、万元、亿元；有明确声明单位时须与金额后缀一致，只有空／text标记可使用完整短金额中的明确单位。

缺数、冲突、单位未知或不一致时，标题显示“授信额度待核实”，不套用示例10亿元或外部不相关金额；记录进入待确认元信息。使用的额度证据ID随交付元信息保留。示例部门、经理、公司和金额均不硬编码为其他项目数据。

DOCX/PDF封面按示例仅展示标题和三行信息；统计期间、实际生成日期、版本、数据快照、保密等原审计元信息仍保存在修订记录，不因未展示而删除。展示字段不得覆盖审计字段。标题由模板生成，禁用本场景自由report_title覆盖；其他场景仍沿用原封面、手工标题与元信息路径。字体沿用[ADR 0015](0015-scenario-document-typography.md)，本次未新增封面信息行的字号或精确空白排布标准。

验证包括金额／来源匹配、单位冲突、默认／指定呈报人员、跨UTC日期转北京时间、伪造日期及标题拒绝、仅三行Word封面读回和其他场景回归。完整仿宋视觉、精确版式和业务签认另行验收；旧项目及发布记录不自动迁移。
