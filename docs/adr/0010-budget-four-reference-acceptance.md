# 预算首期用四份参考报告验收

实施更新：本文件的 `outline.profiles` 已被 [ADR 0011](0011-per-run-source-and-report-plan.md) 取代。四份 DOCX 继续作为验收样本，板块范围和目录由每次需求与材料生成。

用户进一步明确，`results/budget_operations/` 下的预算办月度报告、矿山、冶炼、铜加工三份板块报告均是首期最终交付的参考；`data/scenarios/budget_operations/` 是本轮源材料。此决定补充 ADR 0009，预算办报告仍采用七部分结构，三个板块报告各按自身章节与单位范围组织。

预算场景在同一 `outline.yaml` 中声明三个板块报告 profile，不增加第四个场景包或新的 Agent 入口。主报告保留 42 个主单位及来源表明确列出的 10 个嵌套单位；板块 profile 只选择各自对象，子单位作为三级标题，不与母单位或集团合并行重复汇总。核心仍负责相同的证据冻结、同口径差额、图表来源、版本与质量门禁，CLI 仍是首期北向入口。

参考 DOCX 用于核对章节、对象覆盖、表图与可读性，不作为可复制的事实或正文。数据中标记 MOCK 的内容、集团合并抵销、专项归属和市场时点等未决事项须在报告披露；工程交付可为 `pending_review`，不得称为正式企业经营结论。页面级一致性和业务签认另行验收。
