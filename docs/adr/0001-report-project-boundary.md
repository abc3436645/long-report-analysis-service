# 一个报告项目对应一个场景、对象范围和报告期

用户在2026-10-21第1轮确认：同一期的补件、纠错和改稿属于同一个报告项目，换场景或报告期建立关联的新项目。我们选择把跨期/跨场景关系与报告内修订分开，避免把10月报告当成9月报告的新版本，混淆材料有效范围和历史交付身份。

跨期材料仍可用于当前项目比较；关联项目不自动共享全部有效事实。本决定替代“同一公司所有月份和场景共用一个不断覆盖的报告项目”的做法。

第2轮Q14进一步确认：新报告期沿用已确认的场景/模板版本及对象结构，上期材料仅按明确用途作为比较材料或持续有效参考，不把上期事实自动当成本期事实，也不自动升级配置。材料有效期与具体引用方式在实现契约中继续细化。

用户在Q45确认授信场景的对应边界：一个授信事项/申请、明确业务单位及评价时间范围对应一个项目，补件和审查修订属于项目内版本，新申请或新的评价基准建立关联项目。评价基准日、材料覆盖期间及事项发生日分别记录；基准日后的信息明确其纳入方式，不能因单位相同而混用不同事项或时点的材料。预算月报继续按原报告期规则执行。
