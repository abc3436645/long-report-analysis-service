# 以完整可访问文件作为每轮报告交付契约

用户在2026-10-21第1轮确认：每个生成/修改轮次交付完整Markdown和DOCX，PDF按场景启用；对话返回文件、变更说明和待确认事项，无内容变化的问答提供当前完整版本。选择以完整可访问文件验收，而不要求宿主最终消息逐字重述长报告，是为了在不同宿主中使用同一交付标准，并避免把消息长度或终端打印误当成文件完整性的保证。

该决定明确报告整体是交付单位，局部生成是内部处理方式。

第3轮Q22确认满足场景门槛后可自动标正式版，专项人工确认按场景要求启用。第4轮Q27进一步确认：正文、表图、有效依据、口径或交付身份变化才产生新版本，文字相同但依据/身份变化也属于报告变化；重复请求不重复生效，候选验收后才切换当前版。回退形成新修订并重新验收所选依据，历史不抹除。
