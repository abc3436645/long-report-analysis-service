# 预算报告采用明确排版契约并在交付前检查

用户于2026-10-26提供预算办报告10.5—10.10完整排版要求，并确认本轮修复规格。要求与旧样例字号冲突时，采用本轮明确要求：封面22磅、一级16、二级14、三级12、正文10.5、表格10、图注10.5、目录10.5、页眉页脚9磅。旧样例仍作结构与单位布局参考，不再以“与样例字号相同”作为合规证明。

封面独立一页，包含报告名称、数据统计期间、实际生成日期、分析对象、编制部门、数据性质、报告版本、数据版本和保密说明。经营当月与年初累计分别根据冻结证据表达，文件上传批次不等于经营期间或报告生成日期。报告可读版本与内部修订ID分离；旧报告没有可读版本时，首次建立版本并说明迁移，不回写旧文件。未获指定的保密等级及未明确标识的数据性质保留待确认，模拟数据不能作为真实企业数据。

使用真实Word标题及独立表格样式，覆盖东亚和西文字体、语言及默认样式。字体名称须与实际安装环境核对；本机宋体、黑体名称无可靠匹配时，采用已安装的Songti SC、Heiti SC并渲染复核，不能把写入字体名当作实际使用该字体的证据。

目录优先采用实际更新的动态目录。现有转换入口不提供可靠的目录字段更新能力，采用最终PDF实测页码迭代收敛的中文静态目录及唯一书签跳转；在Word修改正文后须重新生成和检查，不宣称该目录可在Word中自动更新。目录、封面、真实样式、表格边界、重复表头、金额对齐和图表嵌入在发布事务切换当前版本前检查，失败不损坏旧交付。

章节计划仍遵循[ADR 0011](0011-per-run-source-and-report-plan.md)，不固化本轮月份、单位、九章或图表数量。必要逐单位双表和可比图不受50页硬上限限制。排版通过不代替业务签认；Word 2019+、Microsoft 365和常用WPS只有实际测试后才能宣称兼容性通过。

编号由共用预算正文组装逻辑完成，保留已有编号、附录和更深层级；不得只在一次性交付脚本修号。超宽表优先在局部A4横向节展示，并恢复后续纵向；表题随表移动、来源紧接，避免引入空白页。页面尺寸、标题绑定与正文行距也必须在交付门禁实际校验。
