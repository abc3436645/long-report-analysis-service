# 固定更新依据，每项目一个活动运行并统一提交

用户在2026-10-21第4轮Q26确认：一个项目同时只有一个活动更新运行，固定本轮材料和证据依据；独立任务可并行，结果统一提交，宿主无并行能力时可顺序执行。运行中到达的新材料先登记供下一轮使用，旧输入上的结果不能覆盖新状态。

我们选择让正确性依赖统一的输入和提交边界，而不依赖宿主是否具备多Agent能力，也不允许多个宿主同时改写同份报告。代价是单项目更新不并发开启，换取补件、摘要联动、过期结果拒收和跨会话恢复时可以明确判断报告依据。

用户在Q53接受：明确替代本轮要求时停止旧未发布运行，保留已交付版和候选记录，以新要求建立固定输入的新运行；明确取消停止推进，普通补件仍按Q26。工具先撤销旧运行提交/发布资格再安全结束在途工作，迟到结果不得覆盖；发布同时核对基础版本、活动运行及资格。发布若在新操作接受前已完成，则保留为历史，不能假称未交付。具体状态/接口字段为工程契约，尚未运行验证。
