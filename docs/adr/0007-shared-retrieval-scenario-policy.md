# 外部检索是通用模块，使用方式由场景配置声明

用户在C04明确：财务公司尽调、预算经营及其他场景都可以使用同一个外部检索模块，场景配置决定是否使用，检索模块不与具体场景绑定。因此把检索计划执行、HTTP/MCP接入、结果归档和状态纳入通用能力；业务信息需求和适用规则放在场景配置，避免各场景复制检索流程或在模块内按场景名称分支。

这一选择保留替换提供者和跨场景复用的能力。模块提供来源素材而不产生授信模型/等级流程结果或业务结论，不把模块存在等同于所有场景默认启用。

用户随后在Q42修正：必查证据不足可能是检索失败或方式问题，不阻塞进程，需补充说明或请求用户补件；继续报告与必要证据是否满足分开，沿用Q11/Q22的交付身份规则。Q43接受按场景时效复用项目内归档结果，在主体/条件/时间范围变化、过期或用户要求时刷新相关任务，单纯措辞改稿不重查全部；具体清单、时效和提供者仍由配置及实际接入确定。
