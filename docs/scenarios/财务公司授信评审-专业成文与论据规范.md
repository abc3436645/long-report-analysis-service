# 财务公司授信评审：专业成文与论据规范

版本：v1.0｜日期：2026-11-04｜适用配置：financial_due_diligence 0.3.5。

本规范细化[场景规格](财务公司授信评审-场景规格.md)第21节和C09，不改变固定九章、外部额度/评级模型及审批职责。目标是让评审人看清本次授信的偿债依据、决定性风险及可执行条件；专业程度以论据足以支持判断衡量，不以术语密度、篇幅或语气强硬衡量。

## 2. 先形成论证，再写段落

对影响授信金额、用途、期限、还款来源或条件的重要判断，在既有分析底稿中记录下列内容，不新增数据库或要求正文逐项显示字段。

| 项目 | 必须回答的问题 |
|---|---|
| 主张及范围 | 判断针对哪个主体、期间、业务、报表口径和具体授信事项？ |
| 支持证据 | 原件证明了什么？合同、财务记录、业务记录、公司说明各能证明到哪一步？ |
| 计算或逻辑桥接 | 从原始数值或条款到判断，经过哪些计算、匹配或推理？是否有可复算过程？ |
| 反向证据与替代解释 | 哪项事实与判断冲突？余额变化还可能由重分类、抵销、核销等原因造成吗？ |
| 结论强度 | 可以直接确认、仅限公司解释、作有限推断，还是尚不足以形成判断？ |
| 授信影响 | 改变哪项授信要素？影响是否足以阻断审批判断、限制提款或仅要求补充说明？ |
| 正文落点 | 哪一句表达判断及重大限制，哪张表支撑，哪份底稿保留详细核验过程？ |

“有来源”只解决可追溯问题。引用一份财务报表能证明余额，不能自动证明该余额变动的原因。引用履历能证明任职经历，不能证明其已经改善公司经营。由同一材料复制出的两份表不构成独立交叉验证。

## 3. 证据归属与结论强度

已核实事实直接写明，不反复使用免责句。公司提供但尚未独立核验的原因写“据公司说明”；必要时紧接现有证据能支持的范围。分析推断说明连接机制及成立条件；拟议措施写明“建议”，不得当作已经落实的缓释因素。

| 容易越界的表达 | 允许的判断及补强证据 |
|---|---|
| 往来余额下降，因此现金回收改善 | 只能先确认余额减少；现金回收须结合逐笔收款、银行流水及非现金变动调节 |
| 管理人员具有相关经验，因此资金安排能力强 | 履历可说明经验领域；能力和成效须由实际经营结果、授权执行及控制记录支持 |
| 股东实力强，因此偿债有保障 | 区分股东资源、历史支持、拟支持及有效承诺；保障程度取决于责任、能力、期限与可执行性 |
| 已签长单，因此原料供应稳定 | 合同证明约定安排；履约稳定性还需到货、违约、价格及替代供应记录 |
| 资料栏为“无”，因此无账期/无担保/无风险 | 先核对字段定义和记录范围；含义未清时不能把空值或简写变成否定事实 |
| 经营现金净流出收窄，因此经营改善 | 可确认现金流出收窄；经营效率改善还需排除收付时点、保证金及一次性事项影响 |
| 套保端损益加回，因此主业实际盈利稳健 | 匹配现货、期间、会计归属、实现及结算状态，排除重复后再分析；算术汇总仅为条件测算 |
| 提出关联占款压降，因此风险可控 | 建议本身不降低现时风险；须有方案批准、执行权限、回款证据、违约后果和剩余风险 |

缺少决定性证据时，收窄判断并说明影响，不用“可能”包裹强结论，也不把事实一律改写为“不能判断”。正向结论与风险结论适用同一举证标准；不得为追求平衡而凑优势。

## 4. 分析段落与表后文字

一个分析段落围绕一个核心判断展开：先交代当前结论，随后选取关键比较或条款，再解释业务传导及其对授信的影响。结构可依内容调整；工商登记、人员履历等事实段不必硬凑风险结论或量化句。

工商信息小节只输出完整表格，不加表后说明。其他表格承担完整数据，文字负责解释重要变动、集中度、结构差异及矛盾。不得逐格复述；也不得只写“整体良好”“具有优势”“提供基础”。“高、低、改善、稳定、集中、充足”等评价须注明比较对象或期限。同比与环比、年末与中期、单体与合并、自产与代工、存量与流量分别表述。

原因有证据时具体归因；只有业务机制时写清适用条件。收入增加不等于销量扩张，存货金额增加不能只凭铜价上涨解释，应拆解数量、价格、结构与计价差异。无法拆解时仍可分析已证实的占资增加，但不能编造主因。

文字应使用明确主语和可识别的动作。删去无信息增量的过渡句、逐章重复的“持续关注”、关于作者应如何写作的指令。必要的会计口径和重大限制保留在相应判断处，详细定位和核查操作进入底稿。润色前后逐项比对数值、期间、主体、归属及结论强度，禁止以简洁之名删去影响授信意见的限制。

## 5. 九章各自承担的论证任务

| 章节 | 成文应完成的任务 | 不应代替它的内容 |
|---|---|---|
| 公司基本情况 | 工商信息完整入表，基本组织机构情况简列部门；其他小节交代关联关系和单体资金边界，有证据时评价控制有效性 | 工商表后重复说明、组织小节扩写内控评价、履历推导业绩或股东背景推导保证 |
| 公司运营情况 | 还原经营循环、量价费利、采购销售结算与资金需要 | 以收入规模替代实物规模，或将行业常识当公司事实 |
| 公司财务情况 | 解释扩表、盈利质量、受限资金、关联沉淀及现金变动 | 表格复述、余额冒充流量、净利润冒充可还款现金 |
| 外部融资情况 | 区分名义与有效额度，按到期和保证金安排评价接续 | 未用额度直接视作自由资金、余额规模直接证明集中到期 |
| 行业情况及行业地位 | 将行业变化落到公司的订单、加工费、竞争位置和抗压能力 | 无本企业证据的领先、壁垒、优势判断 |
| 风险评价和风控措施 | 说明风险传导、影响范围、建议动作、执行证据及剩余风险 | 对账、关注、加强管理等无法验证的空泛要求 |
| 信用能力评估 | 将已确认信用结果与经营偿债证据核对，解释重大例外 | 材料缺失默认零风险，或把空白评分表写成已评级 |
| 授信要素评估 | 每项要素明确证据、当前意见、未决影响及其处理阶段 | 通篇待确定、重复制度、擅自替外部模型选额度 |
| 综合结论 | 综合本次事项、意见、偿债依据、决定性风险和条件 | 首次出现新事实、重复九章摘要、只说具备继续审查基础 |

结论有依据时明确提出方案；缺关键偿债证据时，明确哪项支持意见尚未成立及其原因。不能因“结论先行”而给出缺证的确定方案，也不能用已完整的企业介绍替代未完成的授信论证。

## 6. 条件的专业表达

沿用场景第21节条件闭环要求，区分审批判断阻断、放款前提、贷后约束和普通补件。写清风险对象、基数、目标/限制、期限、责任、检查证据、触发、处置权限、解除条件及剩余风险。阈值须有本轮证据和授权依据，无依据不填统一15天账期或季度压降比例。

例如关联往来资料不足时，应说明该笔资金尚不能计入确定回款、对何时到期偿债测算产生何种限制；是否限制新增提款、由谁执行、何种证据可解除均需形成方案。不得仅写“加强催收”，也不得把未获批准的自动冻结措施视为现行机制。

## 7. 审阅与验收

每章既有expression审阅按quality.chapter_expression_criteria执行；五项decision审阅负责跨章授信逻辑。expression的locator/quote沿用build给出的章节标题锚点，不改为正文行；审阅者在assessment中记录实际主张及正文位置、证据支持范围、推理、反向证据和意见影响，不得复制相同通过评语。decision审阅沿用claim契约，可将locator/quote定位到实际正文结论。对所有影响授信意见的重要判断进行核对；普通事实校验继续使用既有事实与数值绑定。

结论扩大、因果无据、重大反证遗漏、将建议写成事实或润色删去实质限定，须needs_changes。只有正文已正确表达限制的缺证事项才可gap；gap不等于批准授信。程序检查覆盖、引用、定位和草稿一致性，不能自动判断论据充分性；不增加禁词扫描或自动信用结论。
