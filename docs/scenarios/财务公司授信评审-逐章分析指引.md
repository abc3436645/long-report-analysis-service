## 1. 依据与使用方式

本轮用户新增广州真实报告，并明确第二至第五章表格及金额大、变动大的重点科目分析要求。当前细节以[双样本表格与重点科目分析](财务公司授信评审-双样本表格与重点科目分析.md)补充本文：第二至第五章required_assets声明基础表，materiality_selection及六类focus规定重点明细和表后分析。本文原单样本追溯保留，不再将其表格覆盖视为完整要求。

用户在真实Word测试后进一步要求逐人履历和逐表深入解读，采用[人员履历与逐表经营解读](财务公司授信评审-人员履历与逐表经营解读.md)。management_profiles规定按人完整使用履历；table_interpretation覆盖第二至第五章所有实际表格，counterparty_assessment与operating_stability将占比、账期、供货履约、订单和现金连接到实际能力、优势与风险，不能以表格齐全或只有补件提示代替业务分析。

进一步逐章对照两份Word的实际表现，采用[双稿逐章对照与通用成文要求](财务公司授信评审-双稿逐章对照与通用成文要求.md)，逐小节记录原稿方法、测试稿差距、应保留的证据限制及通用配置落点。business_adaptation按未来公司实际业务选择分析维度，report_expression统一调查报告表达，cross_chapter_consistency要求每节形成局部判断并贯穿事实及方案身份。原稿论证结构可以学习，具体企业事实、技术、参数和正面结论不成为配置答案。

本指引落实用户“读取每个章节特点，细化分析要点和定位”的要求，依据[最终真实报告样例](../../results/financial_due_diligence/关于2026年江铜华北（天津）铜业有限公司10亿.docx)，补充[场景规格](财务公司授信评审-场景规格.md)第10节。样例SHA-256为`6265ae3ae707a0a4ab0b0871ca46f81d88926a63e8999e51f72e585c22e87c88`，原件不改写。

样例正文及17张表格已逐块读取，并检查组织机构图；正文无修订插入或删除。下文P/T定位指`word/document.xml`中`w:body`的零起始子元素序号，P为段落、T为表格，包含空段和表格，不是Word页码。定位只服务于本次样例追溯，不是未来项目的预置证据映射。本次不验收原件版式。

运行入口是[outline.yaml](../../scenarios/financial_due_diligence/outline.yaml)中的`goal/questions`与[analysis.yaml](../../scenarios/financial_due_diligence/analysis.yaml)中的`writing_guidance`。每轮计划保留九章及31个二级标题，各章上下文已有`section`和完整写作指引，无需新增引擎。`analysis_sequence`规定论证方式，`evidence_requirements`规定材料和口径要求，各章同名键提供细节，`review_checklist`供独立审阅使用。

细化内容属于分析及审阅要求。除原工商表、股权表及两个三级标题的既有契约外，不把所有样例表头、年数、户数和三级标题一并升级为固定机械校验；资料不足保留问题与缺口，不能靠复制空表声称完成分析。现有机械校验与审阅提交不自动证明分析充分。

沿用C02—C03及Q44、Q46—Q51：额度来自外部授信模型，等级来自专门流程，期限依据已确认映射；本项目核对与审查。样例中的测算公式、评分权重、AA、三年、信用担保及最终金额均是个案内容，不因样例被称为最终稿而自动成为通用政策。当前`metrics: []`，未新增财务比率、评分或额度计算算子。

## 2. 全文分析定位

按用户最新澄清C08，报告服务于财务公司充分了解业务单位并客观评价综合能力，主动挖掘经营及其他方面的优点、价值和发展潜力，同时排查潜在危险，以支持识别优质基础和风险关注方向。风险分析是其中一个职责，不统领为只找问题。主线是“主体与治理→经营能力及现金形成→财务和融资能力→行业位置及发展条件→风险与缓释→信用结果→授信要素→综合评价和方案”。各章执行comprehensive_assessment，按如下方式分工：

| 章 | 本章应作出的判断 | 向后续章节提供什么 |
|---|---|---|
| 第一章 | 主体治理、股东资源与团队形成何种能力和优势，有何义务及管理约束 | 主体范围、关联关系、管理及资源基础和限制 |
| 第二章 | 如何赚取收益和现金，履约、订单及竞争能力如何，是否具备改善潜力 | 业务模式、经营成果、供销优势、周转及履约条件 |
| 第三章 | 盈利成本、资产运营、现金兑现及偿债能力如何，改善与薄弱在哪里 | 财务质量、效率及现金支撑，预警、原因及口径限制 |
| 第四章 | 融资和资金组织有哪些已落实能力，渠道可用与接续有何条件 | 融资支持、授信占用、提款及到期约束 |
| 第五章 | 外部环境如何影响本单位，已有优势及发展机会能否持续兑现 | 行业位置、经营优势、机会条件与竞争合规风险 |
| 第六章 | 什么可能影响还款，现有控制能缓释多少 | 风险、措施落实、剩余风险和条件性策略 |
| 第七章 | 正式信用结果、真实履约及事项如何支持或约束信用评价 | 信用基础、评级及有效性、事项预警与查询限制 |
| 第八章 | 六类授信要素的来源、必要性及条件是否匹配 | 申请、外部结果与建议的差异及逐要素意见 |
| 第九章 | 综合能力、优势潜力及风险怎样共同支持当前意见，持续与缓释条件是什么 | 优质基础或风险关注方向、可追溯综合评价及方案 |

正文围绕业务问题组织，以事实和变化起笔，连接原因证据、对经营与偿债的影响，最后披露限制和核实动作。原因未证实时分别表达企业解释、分析假设与审查判断，不用“运行良好、风险可控”替代论证。支持与反向证据必须同时进入结论。

每个适用维度主动识别已发生的能力成果、可持续优势、改善或发展条件和制约预警。同一业务安排的价值与风险分别评价，优势不无依据抵销重大暴露，风险也不抹去已核能力。不强行正反各半或凑条数；缺资料只限制相应判断，不直接等于公司差或危险。识别优质基础及潜在危险是研究评审目的，不是新设公司等级或自动授信名单。

统一表达不等于统一结论。每个小节先呈现已核情况并解释，再作证据范围内的局部评价；正文不反复照搬“应如何分析、不能怎样判断”的写作指令或内部核验过程。材料齐备、部分缺失和确实不适用分别处理，已知经营基础不因其他缺件被省略；未知结论也不为贴近样例而补齐。金额单位、指标含义、对手方和主体称谓应在全篇保持一致，取本轮事实而非样本固定答案。

样例多处采用三年及一期的比较方式，可作为深度参考；实际年份及可得期间随本轮材料确定。资产负债表是时点数据，利润及现金流是期间数据；中期同比需要上年同期，年化须有明确方法。不得为了凑齐样例年份编造数值。

## 3. 第一章 公司基本情况

样例P019—P041、T021、T029、T036及组织机构图。特点是先确认法律身份，再解释形成背景、治理与资源关系；股东介绍和主要人员经历用于说明控制及管理基础。

| 固定小节 | 分析重点与所需材料 | 输出及判断边界 |
|---|---|---|
| 一、工商信息 | 登记资料、申请及存续状态；九项工商字段核对，认缴和实收资本区分 | 使用既定两列表格；交代本次事项、基准与重要限制，资本不等于现金 |
| 二、背景情况 | 设立、货币或实物出资、增资、收购、业务变化的时间线；近期规模 | 说明形成当前业务及资金需求的过程，近期收入利润作规模锚点 |
| 三、基本组织机构情况 | 组织图、章程或制度中的治理、经营、财务及法务风控职责 | 图文核对，评价职责安排及证据限制；部门存在不等于内控有效 |
| 四、股权、股东及投资情况 | 逐户股权表、出资、控制依据、股东背景及实际支持记录 | 保留既定两个三级标题；按表序介绍股东，区分资源支持、支持意愿及法律担保 |
| 五、对外投资情况 | 被投单位名称、成立、认缴金额与单位、持股、层级和业务 | 有材料列投资表；连接合并范围、并购产能、关联往来和出资义务，不将认缴额等同账面投资 |
| 六、法人代表及主要管理人情况 | 分人提取姓名、现职及起任、教育专业、职称、相关任职起止时间与单位岗位、兼任；每人独立履历 | 有已知经历须按时间展开，再评管理基础、互补与连续性；缺一人仅该人段披露，不合并概述或从样例补人 |

本章向运营、融资及风险分析提供主体与关联关系。样例的母子公司投资、并购产能、关联借款必须在后文保持同一范围；实际控制人不能仅从某个持股比例推定。

第六节不能仅写法人和总经理姓名后概括“有管理经验”。有相关材料时，分别交代每人的教育职称、主要任职阶段及当前职责，说明经历如何支持生产经营、市场或财务管理；管理有效性还需执行证据。财务负责人履历未提供时为该岗位保留独立缺口段，其他人的已知履历继续充分展开。具体输出与时间冲突处理见人员履历专项指引。

## 4. 第二章 公司运营情况

样例P043—P079、T061、T066、T072、T078。特点是“产品—产能及工艺—盈利模式—产销与收支—采购销售”的业务链，先解释公司如何赚钱，再以多期数据及交易条件验证。

| 固定小节 | 内容展开与材料 | 应解释的关系 |
|---|---|---|
| 一、主营业务情况 | 三级内容为主营产品、产能及工艺、盈利模式；产品规格用途、自营与受托加工、设备及产线、定价和结算；适用时另列在建项目 | 产品差异如何影响加工费或价差；本部及合并产能如何形成；原料、定价、库存和套保如何承担风险 |
| 二、主营产销情况 | 三级内容为主营产销量、主营收支；按实际产品业务列多期产销表、收入成本表 | 数量、价格、加工费和结构如何影响收入利润；现货与套保对应是否有据；与财务报表差异如何解释 |
| 三、原料采购、产品销售情况 | 三级内容为原材料采购、产品销售；主要交易对手名称、产品、金额、占比、结算方式、账期及关联关系 | 集中度、替代性、采购付款与销售回款的时间差如何影响现金需求及信用风险 |

产能注明本部或子公司、设计或实际可用、投产期间；计算利用率先匹配主体与期间。销量大于产量需要核对库存及外购，不直接证明以销定产。自产可能确认全额销售收入，受托加工可能只确认加工费，必须先查本轮口径，不按收入份额直接判断产量贡献。

供应商与客户分别制表，户数取实际材料，客户表头应为客户名称。分母、含税与不含税、主营与全部业务分别标注，不能因销售表与报表不相等就改写原数。长期合作不消除供应集中风险，合同账期短不证明实际回款良好。

上述每张表及合同等补充表均在来源说明后就地解读。产销表回答供货、生产交付及订单能否持续；收支表回答量价加工费和业务结构如何体现盈利能力；供销表分别评估重要公司的交易角色、单户及集团占比、约定与实际账期、履约和替代性，形成采购—生产库存—销售—回款的资金链判断。历史长协、框架合同、基准日在手未交付订单与预算分清，有依据的渠道、交付、质量和成本能力要写出经营效果，不能只列风险或待核事项。

在建项目放在主营业务下的三级内容，列身份、进度、总投资、已投入、后续需求、资金来源与实际到位证据。联系现金流、关联借款及流动性；不把预算或预计收益当实际发生，也不能仅由在建工程余额为零推断无项目。样例P055“可能新增模块”是残留提示，不作为正式分析内容。

### 5.1 重点科目的深度

应收、预付与其他应收不能只写余额。对手方明细说明各期金额、占比及分母，并结合账龄、逾期、关联关系、减值和期后回款；货款、子公司借款、期货保证金分别审查。跨月尾款、正常往来或暂时占用等解释须有记录支持。

货币资金需拆自由支配与受限资金，联系票据开立、保证金、低风险及敞口定义。受限资金增长并不等于自由现金增加，不用同一保证金既抵减票据又覆盖其他债务。存货分析数量、价格、结构及减值，而非只以余额增加推定滞销。

投资、股权和关联往来与第一章投资关系及第二章产能范围互证；短借及应付票据与第四章的机构融资、品种和到期相连。重大性综合金额、幅度与偿债关联，不发明统一数值阈值。

主表、每张科目明细及差异对照表都须单独解释：引用关键余额变动、占比和账期，联系对手方供货或偿付、合同订单及实际结算说明资产和资金组织能力。先解释主表总体资金来源用途，再下钻；明细不止列名称和占比，差异表不止说“待核实”。已有证据支持的经营改善及管理基础与未解决的流动性约束同时保留。

### 5.2 利润和现金流的深度

收入变动区分规模与铜价等价格因素，主业加工利润与收入体量分开。利息费用、利息收入及财务费用不能互换；投资收益与公允价值变动只有在交易及会计依据支持时才归于套保，净抵现货需要匹配证据。

经营现金流与利润、应收及存货占用核对；投资流量区分建设、存款理财及关联借款；筹资净流入解释融资补缺和还款安排，不写成经营造血。最新中期经营现金流为负时，需期后回款、支付和到期安排才能支持暂时性解释；不能用历史年度均为正覆盖该信号。

### 5.3 财务比率的深度与口径

| 三级分析组 | 样例指标需求 | 应回答的问题 |
|---|---|---|
| 盈利能力 | 净资产收益率、总资产报酬率、营业收入利润率、盈余现金保障倍数、营业现金比率 | 薄利来自什么业务结构，收益是否被现金支撑，下降是否有可验证原因 |
| 营运能力 | 总资产、流动资产、应收、存货周转率，两金占流动资产比重 | 高周转是否与产销、账期及期末占用一致，是否存在集中客户或关联占用 |
| 偿债能力 | 资产负债率、速动比率、带息负债比率、现金流动负债比率 | 可快速变现资产与真实现金能否应对短债及票据，受限与期限错配如何影响 |
| 持续经营能力 | 收入及利润增长，订单、产品、客户及现金持续条件 | 增长下降或修复是量价、结构还是其他因素，经营基础是否支持持续偿付 |

以上是应核对的指标需求，按实际业务适用性使用，不代表已确认所有公式。每项需明确分子、分母、利润口径、平均或期末余额、年化方法及比较期间；两金、带息负债等术语也不能替代定义。定义或数据不足则列缺口，已有比率须保留来源和复核限制。确定性计算交程序，宿主不口算；当前场景没有注册这些比率的自动计算能力。

## 6. 第四章 外部融资情况

样例P126—P130、T129。特点是融资总览、按机构的两期授信占用表、征信品种余额及偿付说明。保持无二级标题，正文依次回答：

1. 评价基准时授信总额、已用及未用规模如何较上期变化，各机构集中度和财务公司存量合作怎样。
2. 机构表的额度、占用、未用及合计是否同口径，有无共享、循环、附条件提款或到期续期限制。
3. 流贷、银承、信用证、保证金及敞口的关系是什么；报表余额与征信记录为何不同，查询日与记录覆盖日是否一致。
4. 债务到期、续贷和偿付证据是否支持融资及流动性判断，哪些差异尚未解释。

未用额度不能直接当现金余额，表外融资不能与已入账借款机械相加。已用加未用等于额度仅在同一计量口径下核验，不能把超限或未知差异抹平。有授信不证明无借新还旧、逾期或欠息。融资约束传至风险章、征信、额度及还款来源。

机构授信表和融资口径对照表各自紧接解读，说明机构品种占比、实际提款与续接、期限和采购付款及销售回款是否匹配；已经落实的融资支持应解释经营效果，同时保留拒收票证、共享或附条件等约束，不能只称融资能力尚可或把差异全部留待核实。

## 7. 第五章 行业情况及行业地位

样例P132—P143。特点是把产业链、供需和政策背景落到本单位产品层次、区域、资源与技术优势。输出不是行业资料汇编。

| 固定小节 | 分析重点 | 证据及限制 |
|---|---|---|
| 一、公司所处行业情况 | 产业链位置、需求场景、供给产能、产品与技术分层、区域供需、行业利润及定价方式 | 当前材料或实际执行的检索；说明对本单位订单、加工费、库存和资金的传导 |
| 二、主要行业政策 | 对应产品工艺的准入、产业鼓励限制、环保能耗安全及建设经营影响 | 文件、机构、版本日期、具体条款和适用范围；被鼓励不等于产线已合规 |
| 三、企业优势及行业地位 | 核心竞争优势与行业地位分三级展开，资源、技术产能、产品溢价、区位、客户及资质与经营结果相连 | 排名荣誉列来源、年份、地域产品口径，份额需要分母，领先判断需要可比依据 |

股东背景须进一步核对公司实际取得的供应、融资或其他支持，避免将第一章股东介绍再次复制为已兑现优势。无证据的领先或强信用背书不进入授信判断；有优势也要交代制约和竞争风险。

行业、政策、同业及证据覆盖等每张表后都须落到本公司：哪些产品客户和实际订单可能受影响，资源技术、质量交付、区位和渠道是否已有经营效果，承接需求的能力和投入约束是什么。缺排名份额不等于其他已有经营能力都不能分析；没有订单执行证据，也不能将宏观需求直接确认为本公司增长。

## 8. 第六章 风险评价和风控措施

样例P144—P156。特点是每类风险后紧接措施；细化时须把“措施”再区分为已执行、有证据的现状，与有前提的本次建议。

| 固定小节 | 风险传导与重点证据 | 策略审查重点 |
|---|---|---|
| 一、行业竞争、加工费下行风险 | 需求、产能、产品结构、加工费及利用率→加工利润和现金 | 产品升级、长协和降本有无落实证据，能缓释多少；非加工主体说明标题适用限制 |
| 二、市场价格波动风险 | 原料及销售定价、库存、套保匹配、基差及保证金→利润、订单和资金 | 点价、套保、控库存并不等于风险归零，关注残余敞口及追加资金 |
| 三、应收账款坏账风险 | 客户集中关联、赊销、账龄逾期、期后回款及减值→损失及占用 | 分级、限额、催收及预收的现有执行与新增建议分别列明 |
| 四、财务与流动性风险 | 杠杆、受限资金、短债票据、经营缺口、关联占用及项目投入→支付压力 | 期限优化、回款、融资及支持的可落实性，不能以股东背景替代法律担保 |

每个事项记录支持及反向证据、适用时点、传导路径、现有控制及落实、剩余风险、建议和待核实项。监测及复评条件有依据才量化，不编造负责人、期限或红线；风险程度按已确认政策，缺口不判低风险。

担保或有事项、关联资金占用、诉讼负面事件、在建项目与控制措施必须逐项核对适用性，并在相关固定小节以三级内容安置。适用但缺材料与确实不适用分别说明；同一事项跨材料跨章出现不重复累计。第七章查得的新负面事实须回查本章，而不是只留在检索结果段。

## 9. 第七章 信用能力评估

样例P158—P166、T161。特点是以正式评级结果、征信履约和外部案件记录补充前文判断。样例有评分表，本项目仍只接收、核对既有评级流程产物。

| 固定小节 | 材料及输出 | 不能越过的边界 |
|---|---|---|
| 一、信用评级 | 对象、机构或流程、政策版本、财报期间及审计状态、得分、等级、有效期；已有明细列标准分、得分、合计 | 不从样例继承评分权重、等级释义或自行评级；跨期比较需同规则 |
| 二、征信情况 | 报告主体、查询日、覆盖期、借款及担保、逾期欠息和违约；核对第四章差异 | 单日无逾期不扩大为近三年无违约，记录不自动证明所有用途合规 |
| 三、涉诉情况 | 实际来源、主体标识、查询时间及范围；原被告、标的、案由、审理执行状态、结案与影响 | 无重大案件不等于无案件，摘要先作线索，失败不等于无记录；不得照抄样例供应商名称称已查询 |

未取得结果则说明缺口与影响，不能使用“经查询未发现”掩盖未查询。已有案件结案也要核对执行与余留义务，风险影响联系第六章及方案条件。

## 10. 第八章 授信要素评估

样例P167—P189。特点是额度论证结合外部测算、战略与经营背景、历史合作和用途，再逐项说明期限、担保、利率、用途与还款。可学习其论证顺序，不能把个案政策与计算搬成引擎规则。

| 固定小节 | 审查定位与依据 | 输出及限制 |
|---|---|---|
| 一、授信额度 | 区分申请、存量、模型结果、审查建议和已批准；核对外部底稿、业务需求、现有融资及履约 | 说明模型假设与材料对应及建议差异；涉及调整转外部流程复评，不自行运行样例额度公式 |
| 二、授信期限 | 核对正式等级、现行映射、政策上限、本次期限、回款周期 | 区分最长上限、实际授信及单笔借款期限；缺映射不能用样例三年 |
| 三、担保方式 | 信用、保证、抵质押的适用政策、覆盖、期限及可实现性 | 已生效与拟落实分别列明；评级或股东背景不自动赋予信用方式资格 |
| 四、授信利率 | 当前有效议定方案、定价文件、版本及适用条件 | 已定利率与执行机制分开；缺文件不能仅写按有关规定就视为依据齐全 |
| 五、借款用途 | 采购订单合同、结算与资金计划证明的经营支付 | 区分流贷、建设投资和关联转借；企业承诺及合规结论需本轮依据 |
| 六、还款来源 | 可收回销售货款、回款周期、经营现金净额与到期支付 | 收入不能等同偿债现金，带入受限、占用及回款约束；第一来源与担保或股东支持分开 |

额度底稿若已提供，核对其收入、增长假设、营运资金周转、自有资金、现有贷款与其他资金的主体、期间和定义，追溯结果与建议差异；确定性复核使用已有程序或另行注册口径，不能以模型口算重建外部额度流程。无正式结果仍可完成其他风险审查并披露限制。

## 11. 第九章 综合结论
