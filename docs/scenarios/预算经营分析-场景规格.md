# 预算经营分析：场景规格

版本：业务规格v0.5｜日期：2026-10-21｜状态：Q7—Q30及适用根决策、C04和Q42—Q43已确认；具体字段、场景参数与真实样例继续验证。

依据：[统一架构](../通用长报告项目-统一架构与业务流程.md)、[决策与访谈](../架构细化-决策树与访谈记录.md)、[业务术语表](../../GLOSSARY.md)。本文件记录业务要求，不表示已有可运行场景包。

## 1. 使用者、读者与业务目标

财务或经营分析人员使用工具编制，主要读者为企业管理层和经营会议。报告需要帮助读者理解经营表现、预算差距、相关原因和应采取的行动，不默认承担审计鉴证用途。

每个生成/修改轮次交付完整可访问Markdown与DOCX；PDF按场景启用。对话提供文件、变更说明和待确认事项，普通问答复用当前版本。

## 2. 已确认的业务要求

| 要求 | 具体约定 | 确认来源 |
|---|---|---|
| B01 项目边界 | 一个场景、明确的对象范围、一个报告期形成一个报告项目；同一期补件和改稿为项目内版本 | Q1 |
| B02 对象覆盖 | 企业/集团整体及本次范围内所有经营单位逐一覆盖，重要单位加深；单体企业视为一个对象 | Q8 |
| B03 报告期间 | 首个具体版本为月报，分别评价当月和年初累计 | Q9 |
| B04 比较基准 | 同口径上年同期与相应预算；年度预算与进度预算分开；无月度预算不平均分摊年度预算；环比按材料启用 | Q9 |
| B05 分析链条 | 实际表现→差距/变化→有证据支持的原因→问题/风险→行动建议 | Q7、Q10 |
| B06 判断限制 | 区分已证实原因与待核实假设；依据不足时限定判断，预测/情景测算为后续可选专题 | Q10 |
| B07 缺材料 | 保留相应单位和分析范围，说明缺口、影响、不能作出的判断，交付完整待复核版及补件清单 | Q8、Q11 |
| B08 来源冲突 | 有明确更正/替代声明或已确认来源规则时按范围选择并保留历史；否则请求裁决 | Q12 |
| B09 改稿联动 | 表达修改局部生效；事实/口径/方法/结论变化更新依赖处；明确锁定冲突交给用户决定 | Q13 |
| B10 跨期复用 | 沿用已确认场景/模板版本及对象结构；上期材料按明确用途作比较或持续有效参考 | Q14 |
| B11 完整交付 | 每轮生成/修改交付完整文件；错算、丢章、坏引用、导出失败必须修复，不用待复核绕过 | Q2、Q11 |
| B12 材料格式 | XLSX/CSV、DOCX、可提取文字的PDF；扫描页/复杂版面标明待处理范围，OCR按实际需要接入 | Q15 |
| B13 核心指标 | 收入、明确类型的利润、成本费用及对应实际/预算/同比、差额和完成率；其他财务专题按材料及场景启用 | Q16 |
| B14 集团数据 | 集团报表、单位数据、计算汇总分开；形成合并口径需要明确范围和抵销关系 | Q17 |

| B16 预算版本 | 版本和生效期间保留，项目明确本轮比较版本，局部调整仅作用于声明范围 | Q19 |
| B17 配置扩展 | 实施人员维护版本化场景包，业务用户调整项目要求；已有能力组合用配置，新算法经测试后扩展 | Q20 |
| B18 材料映射 | 稳定映射由程序执行，未知表头/叙述由宿主提取候选事实，核对来源、结构和口径，歧义/冲突才请求用户 | Q21 |
| B19 正式版 | 满足场景必要证据、数据/内容/呈现检查和语义审阅且无阻断冲突，可自动标正式；专项人工要求按场景启用 | Q22 |
| B20 计算规则 | 同口径后算差额；正基数按声明公式算比率，零/负基数默认差额与状态；特殊百分率/有利方向由场景声明，未舍入值参与计算 | Q23 |

| B22 表图和篇幅 | 每单位有核心比较表或缺口说明，图按可比性/分析价值/场景生成；不凑页数字数；模板优先，缺省简洁Word，表可编辑、图嵌入、来源可追溯 | Q25 |
| B23 更新执行 | 每项目一个活动运行、固定依据，独立任务可并行但统一提交；中途材料供下一轮，过期输入结果拒收 | Q26 |
| B24 版本与回退 | 正文/表图/有效依据/口径/身份变化形成新版本，重复请求不重复生效；验收后切换，回退形成新修订并重验依据、保留历史 | Q27 |
| B25 语义审阅 | 关键结论以独立任务按同轮依据审阅，可同模型不同上下文；修复有上限，缺证据披露待复核，必需审阅未执行不标正式 | Q28 |
| B26 事实来源 | 上传材料及有来源/版本的场景资料；外部信息仅由明确任务引入并记录来源时间，不以模型记忆补事实 | Q29 |
| B27 跨宿主验收 | 人工可核对的合成/脱敏样例，三宿主同材料/场景/指令，四轮及异常路径对照事实、计算、覆盖、版本和完整文件 | Q30 |
| B28 外部检索 | 与授信等场景共用通用检索模块，由预算场景配置是否启用及信息需求；不建设预算专属检索流程 | C04 |

“全范围覆盖”与“重要单位加深”是两项要求。重要性影响分析深度，不改变必需覆盖范围。Q24已明确身份、组织与排序规则；真实单位层级、别名和加深条件由项目/场景数据提供，不能凭示例猜定。

## 3. 分析所需的信息范围

已确认需要识别：报告对象及单位范围、报告期、实际与预算的身份、年度与进度期间、同比基准，以及支持原因判断的材料。比较数据必须具有可比口径，未提供与零值不能混淆。

核心指标族、预算版本选择原则、集团/单位数据区别及输入格式已经确认。利润总额、净利润等类型必须明确，不能同名混算；现金流、应收、负债等按资料和需求启用。具体字段、公式、抵销规则、专项数据边界和数值精度仍待细化，不将旧方案示例直接当作正式要求。

Q23已确定默认计算边界：差额为实际减基准；正基数使用声明公式，零/负基数默认表达差额和明确状态。特殊百分率、指标有利方向及展示精度由场景声明；先按未舍入值计算，再展示。不能把成本费用完成率越高直接写成表现越好。

预算版本需要记录身份、生效期间和作用范围。没有明确指定或适用规则时请求裁决；文件较晚上传不等于全面替代旧预算。集团报表缺失时，未经范围及必要抵销核对的单位汇总不能冒充合并数。

报告的主要分析单元应能分别回答：

1. 本对象在当月及累计期间表现如何？
2. 与有效预算及同口径上年同期相比，差距或变化在哪里？
3. 哪些原因有依据，哪些只是待核实假设？
4. 有哪些需要关注的问题或风险，影响是什么？
5. 建议采取什么行动，有哪些前提或信息限制？

这些是内容要求；默认章节见下一节，不要求用冗长重复文字填满所有单元。

## 4. 已确认的默认章节

| 部分 | 内容职责 |
|---|---|
| 执行摘要 | 提炼本轮经营表现、关键偏差、主要问题与行动重点 |
| 整体经营与预算执行 | 从企业/集团整体说明当月、累计及比较基准，不用单位简单加总冒充合并口径 |
| 收入、利润及成本费用分析 | 围绕核心指标解释变化、结构及有依据的原因，明确利润类型和预算身份 |
| 各单位经营分析 | 对所有纳入单位逐一覆盖，分别说明表现、原因、问题、建议与缺口 |
| 主要问题、风险及建议 | 汇总需要管理层关注的事项，保持与各专题和单位分析一致 |
| 口径、材料缺口与证据附录 | 集中列明比较口径、预算版本、来源与缺口；关键限制仍需在相关正文披露 |

章节顺序是默认展示结构。Q25已确认每单位有核心比较表或材料缺口说明，图表按可比性、分析价值和场景要求生成，不设通用固定页数/字数。用户模板优先，缺省简洁Word样式，表格可编辑、图表实际嵌入、来源可追溯。

场景与项目可明确调整结构，不依赖“第几章”作为长期定位方式。单位显示顺序依用户指定/模板、组织顺序、稳定缺省顺序选取，与分析深度分开。

## 5. 业务流程与模块落点

| 阶段 | 要得到的业务结果 | 对应模块 |
|---|---|---|
| 项目建立 | 明确场景、期间、对象范围和模型可见材料范围 | project、scenario |
| 材料登记与提取 | 每个文件有处理结果，事实可回到原文，未提供信息形成缺口 | ingest、evidence |
| 外部检索（按配置） | 启用时取得并归档所需外部素材，关闭时不创建任务；结果核验后才用于分析 | planning、retrieval、adapters、ingest、evidence |
| 口径与来源处理 | 区分期间/预算身份、材料更正与冲突，不能裁决的事项等待用户 | evidence、planning |
| 指标与比较 | 在同口径下执行确定性计算；无法比较时输出原因 | analysis |
| 单位及专题分析 | 覆盖所有单位，分别形成原因判断、问题和建议，标注依据与限制 | planning、composition |
| 摘要与整合 | 摘要和主要结论与本轮有效分析一致 | composition、validation |
| 完整交付 | 所需文件有效，关键缺口披露，保存版本和变更 | validation、rendering、project |

主体分析完成后再形成执行摘要属于主框架的设计方案；任务状态、字段和章节接口会在模块契约阶段精确定义。

检索复用[通用检索契约](../外部服务接入与证据契约.md)，可用于场景声明的行业等背景信息，不能替代单位实际/预算材料。Q42确认必查信息不足不阻塞报告进程，说明限制或提出补件要求；必要证据未满足时完整交付待复核版。Q43确认按场景时效复用项目归档结果，主体/查询条件/范围变化、过期或用户要求时重查相关任务，单纯改措辞不重查。预算默认启用值、具体检索清单和有效期仍需配置。

## 6. 典型多轮情境与业务验收

| 情境 | 需要满足的结果 |
|---|---|
| 个别单位无材料 | 单位不消失；对应分析说明缺什么及影响，补件清单可定位该单位 |
| 缺月度预算 | 不用年度预算除以12冒充已确认月度预算，不将不可比较写成偏差为零 |
| 补充经营说明 | 更新其支持或否定的原因判断，以及依赖该判断的摘要/建议 |
| 更正利润数据 | 更新相关指标、表图及依赖结论；集团总量是否受影响须按后续明确的集团口径判断 |
| 只改第三章语气 | 目标正文更新，其余正文保持；事实和关键判断不被暗改 |
| 事实变化但摘要被锁定 | 保留锁定内容，显式提出冲突并请求解锁决定；不得悄悄覆盖 |
| 新月份建立项目 | 复用结构和固定配置版本，重新确认本期数据身份，上期值仅按明确用途使用 |
| 本轮构建失败 | 不将旧版标成本轮新交付，不以待复核名义掩盖文件或内容硬错误 |
| 同文字但更正来源 | 有效依据变化形成新修订，不能因文字相同跳过版本记录 |
| 并行任务使用旧依据 | 拒收过期结果，不覆盖当前任务和报告状态 |
| 必需审阅没有执行 | 不能标正式版；明确报告检查状态，不把未执行算作通过 |
| 回退到旧稿 | 形成新修订、重新验收所选依据，历史保留；不声称旧内容已覆盖后续新材料 |
