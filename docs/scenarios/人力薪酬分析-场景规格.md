# 人力薪酬分析：配置场景规格

版本：业务规格v0.3｜日期：2026-10-21｜状态：Q37、C05、Q52及Q53—Q55已确认；业务参数、具体章节、配置实例及样例仍需收敛，尚未实现。

关联：[主框架](../通用长报告项目-统一架构与业务流程.md)、[模块契约](../模块设计-数据与执行契约.md)、[访谈记录](../架构细化-决策树与访谈记录.md)。

## 1. 已确认的范围

人力薪酬分析与财务公司尽调、预算办经营分析是并列配置场景，共用通用报告引擎、状态化工具和Agent适配，不挂靠预算或授信流程。场景包负责声明目录、输入、分析口径、公式/算子、方法论、提示词、质量及模板。

Q37确认按部门、岗位、职级等群体分析薪酬结构、差异、预算及人效。人员明细用于统计输入，主报告不默认展示个人薪资或个人排名；可能识别个人的小样本群体按场景规则汇总或隐藏，并说明分析限制。具体样本阈值和薪酬定义未预设。

## 2. 共用的执行约束

- 材料解析先保留来源和候选映射，再核对主体、期间、薪酬组成与统计口径；缺失不当零，冲突不按较晚文件自动覆盖。
- 程序执行分组、汇总、比较及已注册公式；宿主提取未知字段、解释差异、起草与独立审阅，不通过多轮聊天心算或传递一套新数字。
- 对话改稿、补件、更正沿用统一运行/修订契约，持久化事实与章节；每轮生成或修改交付完整MD/DOCX，PDF按配置启用，普通问答复用当前版本。
- 外部检索由薪酬场景配置启用，复用通用retrieval及来源核验；未取得的市场薪酬资料或搜索摘要不能伪装成已验证的比较基准。
- 聚合展示与模型可见范围分别配置。主报告隐藏个人明细不等于原件不能被宿主读取；实际强隔离仍须有存储/权限边界。
- Q52确认事实/口径/结论变化更新关联章节，其余正文哈希不变；表达修改仅改目标，明确人工锁定仍按既有冲突规则处理，不另建薪酬专用改稿流程。

## 3. 配置需要表达的信息（工程建议）

| 配置范围 | 需明确的信息 |
|---|---|
| 对象及期间 | 本次组织/人员范围、分析期间与比较期、部门/岗位/职级映射及组织变动 |
| 薪酬口径 | 采用哪些薪酬组成、应发/实发或其他口径、币种/单位、计提/支付期间、全职当量或人数口径（适用时） |
| 指标与公式 | 结构、群体差异、预算比较和人效的具体定义、所需数据、分母/缺失处理；不在材料不足时发明人效指标 |
| 展示及小样本 | 群体划分、最小展示样本规则、汇总/隐藏处理及限制说明；不预设统一阈值 |
| 章节与方法论 | 每章要回答的问题、所需事实/指标、表图、前置依赖及提示词 |
| 质量与交付 | 群体覆盖、可比性、敏感字段展示、数值绑定、独立审阅及完整文件要求 |

这些是待填契约，不代表已经确认某个薪酬口径、隐私标准、报告频率或企业政策。不能直接照搬预算月报的当月/累计规则。

## 4. 内容结构建议与待决参数

可供配置验证的初稿为：摘要与范围限制；人员及群体口径；薪酬总量/结构；群体差异；预算与人效；问题及建议；口径与证据附录。此处是工程草案，未作为用户已确认的固定章节。

仍需通过业务样例明确薪酬组成、分析期间、比较基准、群体映射、小样本阈值、可用人效数据和企业模板。没有这些信息时说明缺口，不能把算子可运行等同于比较合理。

## 5. 待实施验收

与另外两个场景通过相同核心接口完成首次、补件、更正和章节修改；确定性数值可人工核对；非目标正文按Q52及模块哈希契约校验；人员明细不意外出现在主报告；小样本处理及限制生效；外部基准有来源、时点及可比口径；每轮文件完整可访问。当前合成样例的四轮 CLI 回归、应计期间与小样本抑制已经执行；真实企业口径、外部基准和三宿主实际运行仍待验证。

## 6. v2.0审查：最小口径与fixture契约

下表给出配置实例至少要填什么，不替企业设定真实参数。按Q55，null/未配置、材料缺失、零值及不适用分别表达：坏结构/引用拒绝运行，可明确表达但未填的业务定义使对应计算/展示不可执行，其他满足规则的部分继续完整交付并说明，必要要求不足待复核。项目身份和期间不明仍须先明确，不能用缺口策略跳过。

| 信息组 | 最小信息建议 | 反例或校验意图 |
|---|---|---|
| 薪酬组成及计量 | 纳入的组成项、应发/实发等基准、计提/支付期间、币种/单位、统计人口范围 | 同一笔奖金计提在12月、支付在1月，不能在两个期间作为同口径支出重复累计 |
| 群体与人员口径 | 稳定人员引用、部门/岗位/职级及有效期间、兼任/转岗规则、纳入/排除范围、人数或全职当量定义 | 同一人跨岗位不能默认重复计入总人数；跨期组织调整不能仅按当前部门覆盖历史 |
| 人效定义 | 启用状态、指标名、分子/分母、期间/主体/单位、所需来源、缺失/零分母处理 | 收入/期末人数和收入/平均全职当量不是同一指标；没有分母或业务数据不能由模型补算 |
| 群体展示 | 最小样本参数、合并/隐藏方式、允许展示字段、适用范围及限制说明 | 需用样例核对交叉表/总计是否重新暴露已隐藏的群体，不把设置阈值等同处理已经有效 |
| 外部比较 | 来源、数据时点、地区/岗位/职级匹配、薪酬组成、样本和统计口径 | 不同地区或职级的薪酬中位数不能仅因数字可读取就直接比较 |

这些均属于薪酬配置/输入契约，不新增人力专用引擎。人员明细只在项目允许范围内处理，模型可见字段与主报告展示字段分开；人效所需经营数据作为明确授权、带期间和对象的来源输入，不默认读取另一预算报告项目的事实库。

至少准备一份合成fixture，明确给出样例用的组成、期间、群体、公式和展示参数，并提供可人工核对的预期总量/群体统计、缺口和展示结果。分别覆盖跨期奖金、转岗/兼任、缺少人效分母、小样本处理、来源更正及仅改措辞的正文/资产复用；样例参数不声称是企业真实制度。

本场景当前最缺的是具体实例和答案，而不是更多业务模块。章节草案仍非已确认固定目录；实际企业口径和模板到位后再校准，不能仅用提示词替代上述契约。

Q54的项目覆盖仅作用于场景显式开放的字段并形成固定有效配置，不允许通过“展示调整”绕过个人字段或小样本规则。缺人效公式不计算该指标，缺展示规则不擅自展示受限群体，不能把可运行部分的完整交付描述为全部分析已执行。Q53的改令/取消沿用统一运行资格处理，不增设薪酬专用生命周期。
