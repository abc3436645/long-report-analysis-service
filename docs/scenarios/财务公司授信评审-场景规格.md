# 财务公司授信尽调与综合能力评估：场景规格

版本：业务规格v0.15｜日期：2026-11-05｜状态：C13授权明确公式的营运资金测算及综合额度建议，C12授权规则信用初评，C11确认动态风险小节，C09统领授信决策；其余既有来源、期限及审批边界保留。具体输入、政策适用性、实际来源接入及业务验收仍须核实。

依据：[主框架](../通用长报告项目-统一架构与业务流程.md)、[决策记录](../架构细化-决策树与访谈记录.md)、[术语表](../../GLOSSARY.md)。本规格修正原先“对财务公司自身尽调”的理解，不表示已有运行能力。

## 1. 已确认的业务含义

用户澄清：财务公司需要评估/评审业务单位的授信金额、授信期限或不授信，接收业务单位提供的材料信息及外部专业软件检索信息，开展综合风险评估和尽调。

C08明确全面分析内容（目标层级现按第21节C09执行）：充分了解业务公司的实际经营及其他重要方面，挖掘有证据的能力、优点和发展潜力，同时排查潜在危险，客观真实地评价综合能力，支持识别优质公司和需重点关注的公司。C09下保留这一全面分析要求，早期“侧重风险”不再作为仅找风险的写作导向；额度、等级、期限及审批职责边界不变。

| 要求 | 已确认内容 |
|---|---|
| C01-1 评审方 | 财务公司是开展评估/评审的一方 |
| C01-2 被评审对象 | 业务单位是提供材料、接受授信评审的对象 |
| C01-3 业务目标 | 在授信评审用途下，按C08综合了解经营能力、优势潜力及风险，支持识别优质基础和潜在危险 |
| C01-4 内部来源 | 业务单位提供的材料及信息 |
| C01-5 外部来源 | 外部专业软件的检索信息，是本场景正式取证来源 |
| C01-6 分析方式 | 对两类信息进行综合风险评估和尽调，不能只概述财务数据或罗列检索结果 |

被评审单位的准入范围、集团关系、实际授信政策、审批机构、当前专业软件名称与接口均未确认，不从角色名称推导这些事实。

## 2. 对通用引擎的影响

C04明确外部检索属于通用引擎，预算经营等场景也能配置使用。本场景只声明自身的信息需求和质量要求，不拥有专属检索模块或一套单独的检索生命周期。

### 2.1 事实来源扩展

外部专业检索是本场景需要接收的输入，与单位材料一起登记为报告依据。Q29原先“外部信息通过明确任务引入”的原则继续适用：该场景可以配置检索取证任务，但不因此放开任意联网补事实，也不表示已经授权某个付费服务或取得查询权限。

用户已确认专业信息通过HTTP/MCP服务提供。服务返回应归档并映射为同一证据契约；具体端点、工具名称、认证、权限和结果字段尚未提供。不能将“支持HTTP/MCP接入”描述成已经连通某供应商。普通导出物可沿用上传路径，但不替代该场景的服务取证设计。

企查查类来源与搜索引擎来源需要区分。搜索命中、摘要、原页面以及专业数据库记录的业务含义不同；按Q44核验可追溯原文或专业记录的主体、时点和上下文后，才将关键事实按其支持范围用于报告。无法核实时明确线索身份、待核实项与影响，不将专业软件的结论一概视为适用于本次审查。

外部取证与依据封存的顺序需要明确：拟将专业检索结果在封存前归档到本轮来源清单，再进行综合分析；封存后出现的刷新结果按Q26/Q27进入后续更新或明确重建依据，不混入正在交付的旧快照。具体任务编排仍待工程契约细化。

Q42进一步明确：必查证据不足可能是检索失败或方式问题，不阻塞分析和完整交付，正文说明取得信息的范围、限制及受影响判断，必要时请求用户补件。补件请求不意味着停下等待；必要证据仍不足则沿用待复核身份，接口失败本身不等于业务风险成立或不存在。Q43确认按场景时效复用项目归档结果，主体/查询条件/范围变化、过期或用户要求时刷新相关任务，单纯改措辞不重查。

### 2.2 主体与意见分离

项目需要区分评审方和被评审单位；额度模型、等级评估流程和报告审查也应分开。报告可核对已提供的额度、等级、期限与主体/时点/材料的一致性，不能据此改写外部流程的权威结果。

“报告正式版”沿用Q22的质量身份，不因风险报告完成就推定外部授信业务流程已经完成。实际是否把报告送入审批/业务系统尚未授权或设计，不在本轮增加自动授信动作。

### 2.3 财务计算、外部结果与风险判断

财务指标、对比及明确公式算术由程序执行，材料理解、风险判断和策略起草由宿主承担，关键结论独立审阅。按C12形成信用初评，按C13及第10.23节先算营运资金与贷款缺口，再综合提出额度建议；正式等级及授信批准保留既有流程，期限依据适用等级映射。

若未提供额度/等级/期限或其依据，报告保留对应信息缺口和审查限制，不重新发明评级、授信公式或期限表。外部结果是否为正式版的必需输入由场景质量规则明确；不因此停止其余可以完成的风险分析。

授信管理制度、风险政策和审查清单作为适用性核实后的参考依据；本轮授权执行明确公式，不扩展为重建其他未提供的额度模型。

Q46明确风险报告先行与结果补充是同一项目的不同修订路径。外部结果后补时，复核其与本项目事项、主体和基准的对应关系；无法对应则保留冲突或缺口，不仅把数字贴入旧报告。结果缺失对正式身份的影响仍由场景必要证据要求判断，不能把“允许先写”理解为已经取得结果。

### 2.4 风险策略的表达与边界

按Q47，每项建议说明对应风险、依据、适用条件及待核实项，区分材料中已采取的措施和本次提出的建议。是否已落实措施需有证据，不能把建议改写为企业承诺，也不凭空指定负责人、日期或担保效果。

补件、准入/交易条件、缓释、监测及复评建议可按适用性组合；暂缓/不授信的风险建议须有政策依据，不把材料不足直接等同不授信。额度计算及建议按C13和第10.23节执行；正式等级、合同及批准结果的变更仍提出有依据的复评或审批建议，不自动执行。

## 4. 业务主线与接入契约

业务主线：明确授信事项、业务单位和评价时间→单位材料与通用检索取证→来源/主体/时点核对→财务指标与风险审查→核对已提供的外部授信结果或记录缺口→形成风险策略→独立审阅→完整报告交付。外部结果不是所有分析的前置条件，缺失时继续并披露；其对正式版的影响按场景规则表达。

后补路径：收到外部结果或补充原文→核对事项/主体/版本/时点及期限关系→重新评估受影响发现、策略、摘要和交付身份→验收并交付新的完整报告。与原项目不对应的新申请或新评价基准建立关联项目。

两种MCP角色需要区分：宿主通过MCP调用报告工具，与报告流程通过MCP访问专业来源，是不同的接入方向。字段及来源状态的工程建议见[外部服务与证据契约](../外部服务接入与证据契约.md)，具体连接仍待实测。

## 7. 已确认的审查专题与在建项目（Q49）

首批专题包括经营与财务、偿债与现金流、对外担保/或有事项、诉讼及外部负面事件、关联交易/资金占用、已有增信及控制措施，以及用户补充的在建项目。专题按单位业务、材料与政策判断适用性；适用但缺材料时保留缺口，明确不适用则说明依据，不能仅因没有材料就推断不存在或不适用。这不是穷尽清单或统一监管要求。

### 7.1 在建项目的业务要求与工程建议

用户已确认：存在在建项目时需要说明，并纳入综合风险审查。以下分析维度及字段为落实该要求的工程建议，具体材料清单、计算口径与政策规则仍需样例验证；不自动扩展到全部拟建项目。

| 信息/分析维度建议 | 要回答的问题及限制 |
|---|---|
| 项目身份与建设状态 | 项目名称/标识、所属单位、阶段与实际进度；保留来源、适用时点和未知项 |
| 投入及后续资金需求 | 有依据的计划总投资、已投入与后续安排，核对是否同口径；不能把计划金额当实际支出，缺口不填零 |
| 资金来源及落实情况 | 区分自筹、外部融资等已提供的安排与实际落实证据；意向/计划不写成已到位 |
| 进度及变更 | 核对已提供的进度、延期、投资变更及原因材料，无法核实时明确限制 |
| 对单位的影响 | 结合建设投入、融资安排和有依据的现金流，审查对单位资金需求、现金流和偿债能力的影响；预计收益与已实现收益分开 |
| 风险、措施与补件 | 关联风险事项、现有措施、条件性策略建议及待补材料，不据此重算授信额度或擅定等级/期限 |

在建项目是被评审单位下的业务对象，可在同一报告中有多个；报告项目仍按Q45的授信事项、单位及评价时间划分，不为每个在建项目自动另建报告工作区。同一在建项目跨表或跨材料出现时保留关联，主体或项目身份不清则待核对。

实现沿用场景专题、证据、注册算子、发现与章节依赖。场景声明项目清单及分析任务，已有计算用程序处理，影响判断与文字说明由宿主完成；不在通用引擎中增加“授信专用在建项目服务”。新项目、投资/融资/进度材料补充或更正进入影响分析，更新相关项目审查、单位现金流/偿债判断、策略及摘要；只有依赖实际成立时才联动，不把不同口径金额机械相加。

## 8. 已确认的风险程度表达（Q50）

风险程度独立于授信等级，按已确认场景/企业政策定性分级；缺规则或依据不足则待判定。业务影响、证据充分性及核验状态分别记录，不能以缺材料判低风险，不编造通用分数或授信评级映射。具体等级名称、阈值与适用政策来源仍由场景提供和验证。

## 9. 已确认的风险事项及更新（Q51）

每个风险事项保持稳定身份，记录相关主体/事项、支持及反向证据、适用时点、潜在影响、已采取措施及落实证据、建议和待核实项。同一事项跨材料关联，疑似相同但有歧义则保留待核对，不按关键词机械合并或以出现次数累计风险。

补件、更正或新证据重新评估受影响事项及引用章节，必要时更新策略、摘要和交付身份；旧事项及其原依据保留历史。事项可以关联在建项目等业务对象，但不把一个在建项目直接等同于一个风险；不同风险仍分别表达。

### 10.1 第一章工商信息的必需表格

用户明确“一、工商信息”使用表格呈现，包含企业名称、统一社会信用代码、法人代表、成立日期、有效期、注册资本、实收资本、注册地址、经营范围。配置采用“项目／内容”两列、字段逐行列示，表头及全部单元格为仿宋五号，即10.5磅。缺资料仍保留字段并注明未提供／待核实，注册资本和实收资本分别呈现，不替换概念或移植参考报告金额。

本小节只输出完整工商信息表：以本轮提供的营业执照为主，其他已核材料补充执照未载字段并核验重点信息；经营范围按执照全文列示，不以“等”或“以营业执照登记为准”等摘要代替。实收资本没有可靠依据时写未提供／待核实，不照抄第三方登记快照或添加例行核验句。表格下不另写主体、事项、基准、材料范围或核查过程；这些内容放在其他相关小节。只有重点登记信息有不实证据或重要冲突影响判断时，才在“内容”单元格备注或紧邻表格的锚定批注提示，不把未经核实的值写成确定事实。

内容规则保存在`outline.sections.company.required_tables`，包含`subheading`、`columns`、`required_fields`及`style: compact`；字体字号统一由`scenario.presentation.table_styles.compact`定义。本轮计划不能删除或改变该规则；提交及引用展开后核对该小节中唯一的表格、两列结构、必需字段、重复字段与空值。渲染沿用共享模块，仅对该小节表格设置字体和字号；交付前读回DOCX核对中文、西文及复杂文种的字体和字号，不改变其他表格样式。完整视觉验收仍须主机具备实际仿宋或用户授权的仿宋-简字体，并核对最终嵌入字体。

### 10.2 股权架构表与股东介绍

第一章“四、股权、股东及投资情况”固定先写“（一）股权架构”，正文只输出排名、股东名称、认缴资本（万元）、持股比例（%）四列表格；股东逐行列示，末行在股东名称列写“合计”、排名留空。再写“（二）股东简介、持股情况”，按股权表顺序逐户列持股比例，识别有依据的控股股东，随后介绍企业股东的全称、简称、成立时间、主营产品及可核实的行业地位。两个三级标题用独立Markdown块（`###`）保留，缺资料在对应位置明确标示。

`required_subsections`用`title`及`content`固定两个三级标题、顺序和内容形式（股权架构为table、股东简介为narrative）；简介不能只有表格，须有文字或明确缺口。`required_tables.child_heading`将股权表定位到“（一）股权架构”，`total_row`声明合计标识列、合计行留空列和需要求和的列。两个数值列在引用展开后用Decimal核对逐户之和；所有值完整可比时必须与合计一致。引用尚未展开或值明确标注未提供／待核实时，只比较可以核对的信息，不猜测总额或默认100%；有舍入或口径差异时明确披露并核实，不擅自设定容差放行。股权架构表后不加正文，来源定位与核查说明放锚定批注，数值单元格使用数值引用或明确缺口。

控股股东依据本轮股权、表决权及特殊约定识别；依据不足写待核实，不能把控股股东自动写成实际控制人。示例中的股东人数、名称、出资金额、持股比例、主营产品、排名、荣誉和行业地位仅为写法参考，不能作为其他项目的预置事实；每项背景须有本轮来源及适用时点。本轮未新增股权表字号要求，沿用默认表格样式；工商信息的仿宋五号规则仍只作用于该表。

### 10.5 第一章背景情况的三级结构

“二、背景情况”固定依次写“（一）公司概况”“（二）发展历程”“（三）近三年经营业绩”。`outline.sections.company.required_subsections`约束三级标题、顺序和各部分须有正文或明确缺口；一级、二级标题及其他小节不变。程序检查结构，具体事实覆盖由独立审阅核对。

公司概况写全称、简称、成立时间、是否合资及合资各方、当前股东与股权结构；持股信息与本章股权表一致，未获证实的合资性质不推定。发展历程按有证据的设立、出资、增资、收购或业务转型节点，说明对当前业务的影响，不以空泛发展叙述替代。近三年经营业绩逐年列最近三个完整会计年度的营业收入和利润总额，注明年份、金额单位及单体或合并口径；不能以净利润代替利润总额，缺某年或口径不可比须逐年说明，不用中期数据补作全年。可简要比较收入规模与利润变化，详细盈利及偿债分析留第三章等相关章节。

### 10.6 第一章基本组织机构情况

“三、基本组织机构情况”仅依据本轮材料简要说明公司的主要部门名称、分组及可核的隶属关系，不扩写部门职责、人数、授权制衡或内控有效性评价。公司部门机构图可待后续绘制后作为本节补充，当前不设为必需图表；缺图不能使已知部门介绍变成核查清单。图文有影响理解的重要冲突时，在相应位置提示核实。

### 10.7 第一章对外投资表与持股公司介绍

“五、对外投资情况”先列固定四列表格：持股公司名称、成立日期、认缴金额（万元）、持股占比；每家持股公司逐行列示。之后按表序逐家介绍公司的全称、简称、成立时间及股权构成，股权构成写已核股东和持股比例。认缴金额与被投公司注册资本、实缴额及账面投资余额分开，持股占比明确百分比口径；缺资料逐项标注，不补造持股公司。材料明确无对外投资时表内标明无对外投资并简述依据，资料不足时保留表格及简介缺口。

`required_tables`为该小节固定表头、唯一表格和非空数据行；持股公司数量随本轮事实变化，因此本表没有固定字段行或合计行。结构由程序核对，逐家简介及金额身份由独立审阅核对。投资义务、经营协同和偿债作用放在相关财务及授信章节分析。

### 10.8 第一章法人代表及主要管理人履历

“六、法人代表及主要管理人情况”按本轮材料中的主要人员逐人分段介绍履历。每段以姓名及现职起笔，按已核材料写教育专业、职称资格、相关任职起止时间、单位与岗位，以及现职起任和兼任；同一人兼任多职只写一份。正文仅保留履历事实，不添加管理能力、团队互补与连续性评价，也不穿插核查说明或结尾总结。个别字段缺失在该人员段落的锚定批注提示，整份履历缺失在本节标题的锚定批注提示；不编造人员或设置空白履历段。履历内容充分性及正文边界由独立审阅核对。

### 10.9 第二章主营业务情况的展开与证据边界

“一、主营业务情况”围绕业务概览与商业模式展开：主要产品及服务、各业务线收入金额与占比及可比期间变化，客户类型、定价收费和交付回款方式；适用时说明市场规模、增长、竞争格局、公司份额和差异化。制造业进一步说明产能及利用率、设备状态、工艺、良率、质量体系和资本开支需求；研发技术说明投入、团队、核心技术与知识产权、技术来源和外部授权依赖、产品迭代及商业转化；有在建项目时说明进度、已投入及资金去向、剩余投资、后续资金需求和来源落实。

上述是有相应资料时的可选侧重点，不是每份报告的必填清单。“主营业务情况”固定二级标题保留，正文按已提供材料选择重点；没有研发与技术投入等某类资料时，直接省略该类段落及三级标题，不写空白项或例行“未提供／待核实”，也不据此推断企业没有相关活动。部分资料可用时只写有证据的事实，不强求该类所有字段齐全；已有材料涉及的重点仍应充分展开。占比、增长、利用率、份额须明确期间、主体、分子分母及可比口径；知识产权与质量认证须核对权利人、状态和适用范围，计划投入和预计收益不得写成已实现结果，不作无依据的领先、稳定或高增长判断。第二章后两小节承接详细产销、采购销售分析，第五章展开行业政策和同业比较；本节不重复整表或整章分析。结构和证据充分性由独立审阅核对，不新增机械关键词门禁。

### 10.10 第二章主营产销情况的期间比较与异常解读

“二、主营产销情况”分别以“（一）主营产销量”“（二）主营收支”展开。按本轮可得材料分产品、分业务列近几年完整年度及当年截至评价基准的产量销量、收入成本和可核毛利，注明主体、期间、累计或分月分季、实物与金额单位。逐表描述关键规模和结构，再分析变化；已有同口径上年同期数据时计算同比，有相邻月度或季度等同频数据时计算环比。年度全年与当年累计不得直接作为同比，跨主体、跨产品或跨频率不硬算变动率；缺可比期时仅分析已有数据。

对突然上升或下降的产销、收支和毛利指标，按绝对变动、基数、历史波动及业务影响选择重点，追查订单交付、产线与库存、客户需求、价格加工费、业务结构、成本及结算等对应证据。分析分别交代已核事实、企业解释、反向证据、收益和现金影响及尚存限制；优势需连到实际执行和经营效果，风险需说明形成机制与传导，不用单期升降或宣传性形容词替代完整论证。表格和正文的数据口径及结论充分性由独立审阅核对，不新增自动异常阈值。

### 10.11 第二章原料采购、产品销售的表格与关系分析

“三、原料采购、产品销售情况”分别列两张独立基础表：有交易数据时，“主要供应商表”固定表头为供应商名称、产品、采购金额（万元）、占比、结算方式、账期；“主要客户表”固定表头为客户名称、产品、销售金额（万元）、占比、结算方式、账期。两表分别列本轮可核对手方，注明期间、主体、金额及占比分母；结算方式与账期分别填列，不混用采购与销售金额。无整表资料时各按基础资产规则具名披露对应缺口，不为凑表编造对手方或空行。两表之后分别就具体金额、占比、合同与实际履约作解读。场景的`required_tables.asset`只对实际输出的对应表核验六列表头及所属小节，缺整表仍由`required_assets`披露缺口。

有完整同口径名单和总额时，说明前五大供应商占总采购、前五大客户占总销售的比例；不足五户则只说明已知户数和覆盖范围。集中度还需结合单户及同一控制集团、合同期限、续签和实际履行、替代来源、账期与回款，才能判断依赖深度和稳定性。主要客户背景和舆情仅按实际取得的资料说明，核对报道来源、时间、涉及主体及已证影响，媒体线索不直接等同违约。客户与供应商重叠或关联、新增大客户、交易前后近期入股，只在有名单、股权及交易时间等材料时分析；新增或入股本身不等于异常。关键合同的控制权变更条款须核对触发条件、同意或终止权及实际控制权变化，不能仅凭条款存在认定合同会终止。缺相关材料时不扩写推测性风险清单；优势与风险结论均须有事实、机制和实际效果或影响的完整证据链。业务内容充分性由独立审阅核对。

### 10.12 第三章资产负债表的完整列示与重点解读

“资产负债表”小节先按本轮可得材料，完整列示近几年年末及最新中期或评价基准时点的资产、负债和所有者权益各科目、小计及合计；保留原报表名称、层级和金额，注明主体、单体或合并范围、单位、时点和审计状态。完整列示与重点分析职责不同：主表不因某科目金额小而删行，正文不逐行平均复述。缺某期或明细时如实指出缺口，不补零、不拼接不同主体或口径。最新时点与上年末比较须标明跨度，不误称同比；只有同口径上年同日或同月末数据才可作时点同比。

表后先解释资产、负债和权益总体规模、结构及资金来源用途，再按金额较大、变动较大或性质重要筛选明细，重点覆盖货币资金、应收账款、其他应收款、其他应付款、存货、长期股权投资和负债，同时检查其他触发项目。每个重点项目用余额、占比及分母、可比时点和差额确定分析对象，再用附注、交易或合同、账龄、受限、减值、到期与期后收付等对应证据解释性质、成因及对可支配现金和偿债的影响。稳定大额、余额下降和重分类也应评估；无原因证据时只陈述已证变化和判断限制，不把企业解释当已核事实，不因单项增减推定资金充裕、风险消失或经营恶化。无统一金额阈值，分析重心按本单位实际影响确定；完整性与结论充分性由独立审阅核对。

本轮材料中，货币资金、应收账款、其他应收款、其他应付款、存货、长期股权投资、负债，以及其他影响正常经营、资金占用或偿债项目如有相关明细表、附注表或对照表，须在本小节全部输出并逐表作有证据的深入解读。重点筛选决定分析重心，不构成省略已有表格、金额较小但性质重要数据或不利信息的理由。逐表说明关键余额与变化、占比及分母、主体期间和口径、形成原因、受限与回收偿付条件，以及对经营和可用现金的影响；以本轮原表、附注、合同、流水、账龄、减值和期后收付等可追溯材料支撑事实与因果判断。企业说明、已核事实和审查推断分开表述，正反证据一并呈现，结论与证据强度相称，不刻意夸大或淡化；缺资料时披露对应缺口及其对判断的限制，不补造表格或结论。

同样，本小节能正向反映公司经营运行、资产回收、可用资金或偿债状况的可核实数据，即使原材料未排成表，也须按科目、期间或对象整理成表并逐表解读。表中明确主体、时点、单位、来源及可比口径；正文解释积极变化的形成过程、已实现的经营或现金效果、持续条件及相反证据，不能把单项账面改善或企业自述直接写成经营优势。异常情况及重大金额变化须说明量级、比较基准、已证原因和对经营或偿债的影响；原因不明或材料冲突时，正文保留已知事实与实质限制，在对应表格或分析段落的锚定批注提示具体待核事项和补件。批注不能代替影响判断的正文，不用统一金额阈值代替本单位实际影响。目标是完整了解公司运行情况，有利和不利结论均须有完整证据链，专业、准确且不夸大、不遗漏。

### 10.13 第三章利润表的完整列示与盈利质量分析

“利润表：”小节先逐行列本轮可得近几年完整会计年度及最新累计或单期的原始利润表，保留收入、成本、费用、损益、税费及各级小计合计的原科目、层级、符号和金额；标明主体、单体或合并范围、期间起止、累计或单期、币种、单位及审计状态。缺某期或明细如实披露，不用摘要替代主表，不补造数据。年度与中期累计不直接作同比；同比只用同范围上年同期，环比只用相邻同频单期，累计数还原单期须有可核差额。表后按收入成本、毛利、费用、减值、投资及估值损益、营业外项目和所得税解释营业利润、利润总额与净利润的形成。

勾稽先用程序或可核原表复核小计合计、营业利润至净利润的关系及损益符号，再对财务费用中的利息费用、利息收入、汇兑、手续费等逐项调节；不能假定“利息费用－利息收入”必等于财务费用。核对舍入、列报及主体期间后仍无法解释的差额直接列为疑点，注明差额和受影响判断，不擅自改表或仅凭差额定性舞弊。按可比期间比较同比、同频环比、各项占收入比重、绝对变动及历史波动；资产回报指标另核对平均资产等适用分母。同行比较须核对业务、会计政策、期间和来源，无可比资料时不声称偏离行业，也不预置任何行业“正常”毛利率或统一风险阈值。

收入结合分产品或分部、确认政策、总额净额法及期末集中确认检查；毛利结合成本归集和可比业务；费用结合规模、研发资本化、关联方代付代摊；减值核对计提时点，所得税核对税率及适用条件，投资收益、公允价值和其他非经常项目区分已实现与未实现，并在分母有意义时计算占营业利润比重。核心利润及其比率先确认剔除口径、分类和计算输入，按已确认口径为负时如实说明；利润分母为零或负时不硬算误导性占比。分项附注和明细有数据时列示并逐表解释，与主表合计核对；不因利润为正就推定主业收益或现金创造稳定。

联查第二章产销收支、资产负债表应收预付存货和金融资产、现金流量表经营收现与筹资、第四章有息负债。收入与应收增速、毛利与库存预付、利息收入与资金负债、投资收益与投资资产、利润与经营现金、费用率与人员业务规模等不匹配时，先核主体、流量存量、期间及交易机制，再判断其意义。每项疑点在底稿记录异常事实、追问、核查资料、可量化时拟调整科目及金额与计算依据；不能量化则写明限制，不编造调整值。已证盈利影响和重大限制在正文说明，核查步骤与补件在锚定批注提示。正向与负向判断同样需要事实、因果或计算桥接、反向证据和适当结论强度；比率建议留“财务比率及分析”小节按可用数据和已确认公式列示，不因提供通用指标名称而默认算子或阈值已经具备。

### 10.14 第三章现金流量表的完整列示与现金质量分析

“现金流量表：”小节先按本轮材料完整列示近几年完整会计年度及最新累计或单期的原始现金流量表，逐行保留经营、投资、筹资活动各项流入流出、小计和净额，及原表列示的汇率影响、现金及现金等价物净变动与期初期末余额；保持原科目、顺序、层级、符号和金额。注明主体、单体或合并范围、期间起止、累计或单期、币种、单位、审计状态和来源。缺某期或明细逐处说明，不以三类净额摘要替代完整主表，也不据利润或资产负债表反推缺失的现金流项目。

先用可核原表或确定性计算检查各类流入减流出与净额、三类净额及汇率影响与现金净变动、期初与期末现金等价物的关系；与资产负债表货币资金联查时说明现金等价物、受限资金和主体时点差异，不能机械要求余额相等。解释不了的差额按项目、期间及影响列为疑点，以本轮原表为准，不用跨表推断改写原数。完整年度之间及有依据的同期间同比可以比较；环比只比较相邻同频单期，累计数须有相邻可靠累计数才可还原单期，基数为零、负值或口径不一致时说明金额和限制，不硬算增长率。

按经营、投资、筹资三类逐项解释重要流入、流出及净额，以金额、绝对变动、历史波动、可用性和偿债影响选择重大异常及变化。经营现金与收入、利润、销售收现、采购付款、应收预付存货及大额“其他”收付核对；投资现金区分建设、理财、股权及关联借款；筹资现金核对新增与归还借款、利息股利、续接和到期压力。已有现金流明细、利润到经营现金调节、货币资金口径对照等相关表格时逐表列示解读。每项已证改善或恶化均说明原值、可比差额、形成机制、现金占用或释放和持续条件；利润为正而经营现金为负、融资补缺或最新中期转弱是核查线索，不能无据认定季节性、风险消失或持续恶化。事实、企业解释和审查推断分别表述，正反证据与不确定性保留在有边界的结论中。

建议可围绕本单位已证实的主要现金约束或改善机会提出，但须选一条主方向，写清具体动作、适用前提和可观察结果；其他建议从属于该方向，不把建议写成已落实措施或保证效果。影响授信偿还的限制写正文，待核原因、所需材料及核查步骤可在对应表格或段落的锚定批注提示。跨章节资料仅用于相互印证，本轮用户提供的原始数据是列表示值的依据；来源冲突并列披露，不挑选有利数字形成结论。内容充分性与建议侧重由独立审阅核对，不预设统一金额阈值或自动风险评分。

### 10.15 第三章财务比率表与四组分析

“财务比率及分析”小节的基础表按下列四组、16项指标固定行名与顺序。列为本轮可得近几年完整年度和最新期间，期间与主体随当前项目确定，不把用户给出的示例年份、数值或结论写成通用配置。中期列说明累计区间，时点指标注明截至日；每个单元格填本轮可追溯的原始指标或确定性计算结果，缺定义、缺输入、不适用及不可比时逐项标明状态与原因，不因缺值删行或以样例补数。

| 组别 | 固定指标 |
|---|---|
| 盈利能力 | 净资产收益率、总资产报酬率、营业收入利润率、盈余现金保障倍数、营业现金比率 |
| 营运能力 | 总资产周转率、应收账款周转率、流动资产周转率、两金占流动资产比重、存货周转率 |
| 偿债能力 | 资产负债率、速动比率、带息负债比率、现金流动负债比率 |
| 持续经营 | 营业总收入增长率、利润总额增长率 |

每项核对公式、分子分母、平均或期末余额、单体合并范围、期间、单位及年化方法。现有`financial_metrics`只自动计算已注册的部分描述性比率，不能从名称相近就认定公式一致：营业收入利润率不自动等于净利率，速动比率以倍或百分比展示需明确换算；总资产报酬率、盈余现金保障倍数、营业现金比率、两金、带息负债比率等须取得本轮适用定义。材料直接给出而尚未独立复核的指标可保留来源及口径待核身份；需要新算但公式或输入未确认时不由模型口算填列。年度与未年化的中期指标不直接比较，增长率要有同范围上年同期；零或负基数不硬算无意义百分比。表格结构固定不等于已验证所有指标值。

表后按四组分别分析：盈利能力连接主业利润、费用、非经常项目和现金兑现；营运能力连接产销、收付账期、应收存货及关联占用；偿债能力连接受限资金、短债到期、有息负债和经营现金；持续经营连接收入利润同期间增长、订单履约、投资需求及资金持续性。每组引用具体数值、可比变化、形成机制、反向证据及对本次授信的实际影响，不能只描述升降或套用统一行业阈值。外部营商环境、国际金属价格及市场变化仅在取得有日期的可核来源，并证明本公司产品、定价、库存或套保传导时纳入解释；市场变动本身不证明公司经营改善或恶化。指标口径及解释充分性由独立审阅逐项核对，不新增未经确认的计算算子。

### 10.16 第四章多期机构授信用信与融资影响分析

第四章保留“机构授信用信两期对比表”的基础表契约名称，实际列示范围扩展为本轮可得近几年各年末及最新评价时点，不受两期限制。按原材料逐一列银行和其他融资机构，保留历史退出机构，不只选择大额、主要银行或有利变化；按机构及必要品种列各时点的授信额度、已用、未用及同口径合计。主体、时点、币种、单位、来源、是否含财务公司、敞口或全口径、共享及低风险品种范围就地说明；跨年余额不累加，不同币种无可核汇率不合计。某期或某机构缺件逐处标明，缺失不填零，来源覆盖不全时不宣称列全公司所有外部融资。

主表附列或配套期限明细按材料说明授信起止及有效期、具体借款或融资余额和到期日、担保抵质押及提款条件，有依据时补利率成本和续接状态。授信有效期与单笔债务期限分别保持，未知项注明缺口。批复、合同额度、品种占额与账面债务分别核对；综合额度与共享子额度不重复计入，已用加未用仅在同口径成立时勾稽。名义未用额度须核共享、品种、保证金、抵质押及审批条件后才讨论实际可用性，未落实续贷不作为确定资金来源。

各融资表与期限明细后引用具体时点余额、差额、占比及期限条件，解释渠道和品种集中、机构进入退出、使用及剩余额度、到期和续接的变化。结合第二章采购结算、订单交付、回款周期及第三章受限资金、往来占用、经营现金和债务，分析融资对经营周转、成本及偿付的已证支持与约束；重点围绕实际影响最大的渠道可用性、期限匹配或现金缺口，不以机构多或总额度增长直接认定融资稳定。可扩展建议须有对应事实、动作和前提，不能保证效果或将建议写成已落实。

结论对应本轮适用的授信批复、合同、用信台账、征信、担保和实际收付证据，记录来源日期及覆盖范围；差异核对主体、品种和时点，不能笼统以“口径不同”消除。企业解释、已核事实与推断分开，有利与不利发现均保留，异常及重大变化追查原因，证据不足则限定判断。影响经营及偿债的实质限制写正文，核查及补件细节可放锚定批注。仍保持第四章无二级标题；本节为配置与独立审阅要求，不宣称已经生成或验收新报告。

### 10.17 第五章行业、政策与企业地位的经营传导分析

保留“一、公司所处行业情况”“二、主要行业政策”“三、企业优势及行业地位”三个固定小节。先依据本轮主营产品、产销收入结构、营运模式和区域确定细分行业，再分析行业发展阶段、市场行情、上下游、竞争和产业协同。发展阶段以需求、产能利用、技术演进等可核证据判断，不能仅据行业名称贴标签；价格资料注明产品、地域、期间及现货期货等口径，结合本公司合同定价、库存、套保和结算，解释市场如何影响订单、成本、利润及现金，不以宏观行情替代本公司原因证据。

上下游联系实际供应商客户、采购销售、集中度和可替代性，竞争结合可比产品、产能技术、价格成本、质量交付及进入退出条件。产业协同核对园区、区域集群、集团或上下游在原料、能源、物流、技术及订单等环节的合作与已发生效果，同时说明依赖、切换及资源约束；地理相邻、同属集团或框架协议不能直接认定协同收益。行业竞争格局基础表和适用的同业比较表按上述维度列证据，并逐表说明对本公司的实际影响。

政策分析覆盖国家产业政策、国家或区域发展规划，以及公司所在地或项目所在地政府政策。优先核对发布机关原文及正式实施细则，记录发布主体、文件名称编号、发布生效及修订有效状态、适用地域、对象与具体条款，结合本公司产品工艺、资质、项目、申报批准和履行情况解释支持与约束。规划目标、符合申报条件、已获批和实际到位分别表述；鼓励类行业或扶持地区身份不证明产线合规、补助已获或政府承诺支持。适用性及实施依据不足时保留相应判断限制，不编造政策、优惠金额或落实进度。

企业优势和行业地位联查前四章经营、产品、利润现金、债务及融资事实，选择对单位收益、订单、资金占用、合规投入和持续偿债最重要的因素深入解释。排名、份额及领先判断须有产品、地域、年份、分母和可比依据；缺排名不妨碍评价已证实的具体能力，但应限定行业地位。已兑现优势、发展机会、竞争压力和限制均须呈现，预测与计划交代条件及不确定性，来源观点、企业解释与审查推断分别归属。表后解读及实质限制留正文，核查补件可放锚定批注，独立审阅不得以行业资料篇幅替代公司分析充分性。

### 10.18 第六章动态风险归纳与七要素闭环

按用户2026-11-05最新确认及[ADR0029](../adr/0029-dynamic-evidence-based-risk-sections.md)，第六章只固定章名，小节从原始材料及前文经营、财务、融资和行业发现高度归纳，按对本次授信的影响及紧迫性命名排序。原四个固定风险小节取消；其他27个固定二级标题继续保留。章首先突出3至5项实际关键风险，不足时不凑数，次要风险随后；没有已识别风险时说明已核范围和判断限制，不编空标题或声称风险不存在。现行规则以本节为准，第11节及后文历史版本所述31个固定标题不再约束新项目第六章。

章节遵循风险识别→风险评价→风控措施→剩余风险与结论，每项采用同一七要素结构，可用要素／内容表或同名段落，报告内保持一致：

| 要素 | 交付要求 |
|---|---|
| 风险描述 | 一句明确具体问题和对象 |
| 事实依据 | 回指前章数据、交易或事件及本轮原始来源，区分已核事实、企业解释、判断与待核 |
| 影响程度 | 说明利润、现金、本息偿付传导；输入和方法成立时确定性量化，否则列已知敞口、情景及限制 |
| 发生可能性 | 按适用口径列高、中、低、时间范围及理由；已发生事项另标现状，证据或口径不足待判定 |
| 风险等级 | 综合影响及可能性，注明方法及证据；沿用Q50，不自创阈值或矩阵，不替代正式信用评级 |
| 风控措施 | 对应风险、责任岗位或主体、完成节点、验收证据、监测触发及处置权限，区分已落实、拟议和待批准 |
| 剩余风险 | 分别说明现有措施后暴露及建议落实后的条件性暴露、执行限制和复核条件，不能提前抵减风险 |

主题清单用于检查适用性，不是固定目录：偿债流动性、盈利质量与持续经营、供销客户合同、资产质量、关联交易治理、合规法律、税务、行业市场与套保、财务信息真实性，以及实际交易或项目风险。财务公司授信优先评价经营现金第一还款来源、本息覆盖、额度期限匹配、融资依赖和续作、用途与贷后管理；资产处置、担保和股东支持另核权属、可执行性、时间及金额，不取代经营还款判断。并购估值、整合及补偿、IPO披露等检查仅在实际事项影响借款人时适用，不将其他机构的完整清单机械套入。

措施从提款前核查、授信结构合同、增信担保、贷后管理中选择对应动作，具备针对性、可操作性及可检验性。原材料未确认责任或时点时，可提出明确标为建议的岗位和业务节点；未定数值、阈值或期限说明待确定及影响，不虚构已承诺人名或完成日期。核查不能凭空将疑点转成确定损失，量化与压力情景须有输入和方法；核心利润等定义沿用前章核定口径。重大限制留正文，补件细节可用锚定批注。事项稳定身份及支持反向证据贯穿前文、第八章条件和第九章意见，最终授信决定及外部额度评级流程权限不变。

场景第六章声明`dynamic_subheadings: true`并省略`subheadings`，沿用现有可选标题契约，正文用实际二级标题生成小节；第四章显式空列表仍表示无二级标题。审阅覆盖从实际正文收集动态风险小节及表格，独立审阅评价七要素、排序、量化评级依据、措施执行与剩余风险，不能只凭字段齐全放行。旧冻结项目保留原目录，配置更新不等于已生成或验收新报告。

### 10.21 第七章征信报告与实际履约的综合评价

“二、征信情况”主要依据本轮提供或实际取得的征信报告和公司履约行为作专业总结。先核报告来源、公司全称及身份标识、出具日、查询日、记录覆盖期与评价基准；不同公司、股东关联方和保证人的记录分别保持。收到历史报告不等于本次已查询，未实际查询时按“已提供报告显示”归属，不虚构查询行为。

按报告实际覆盖概括借贷、担保、未结清及已结清业务、适用风险分类、当前和历史逾期欠息等异常。异常有依据时说明业务或机构、金额、时间、持续与清偿纠正状态；历史已结清不能表述为从未逾期。展期、借新还旧或重组核对性质和原因，不仅凭名称认定违约或风险消失。结合合同到期本息和支付条件，与还款台账、流水、结清或债权人证明等材料核对实际还本付息及履行义务，保留本财务公司和其他机构已有履约证据，区分企业说明与已核事实。

表述以“报告覆盖及主要记录、实际履约与异常处理、综合评价及判断限制”为逻辑，既总结已证实的正常按期履约，也说明异常及其信用影响，不堆录项目或仅贴“征信良好”标签。与第三章债务现金和第四章融资数据按主体、品种和时点相互印证，不能强行调平或累加多时点余额。材料部分不足时，已有记录照实评价，缺口仅限定受影响判断；单一时点无逾期不能扩大为近三年无违约、无其他负债或用途合规，缺报告也不等于公司信用差。

总结须限定公司、期间和证据覆盖范围，必要时补异常明细，不设置新的必填表格。影响风险、信用初评征信项及授信意见的发现传至相关章节，不能凭概括性的征信结论直接默认满分。实质限制保留正文，核查步骤和补件可用锚定批注。此配置不代表已经查得实际征信报告或完成公司履约验收。

### 10.22 第七章涉诉信息核验与实际影响评价

### 10.23 第八章营运资金测算与综合授信额度建议

2026-11-05用户要求第八章“一、授信额度”先按所给公式计算，再结合公司营收、财务、股权背景、主营产品、市场地位和营运能力、征信及债务形成最终建议，并明确示例仅作示意、以实际计算为准。C13及[ADR0032](../adr/0032-working-capital-and-credit-limit-recommendation.md)取代此前仅复核外部额度的限制，不重新实现未获授权的其他模型，不代替正式审批。

营运资金量＝上年度销售收入×（1－上年度销售利润率）×（1＋预计销售收入年增长率）÷营运资金周转次数。

流动资金贷款额度（测算资金缺口）＝营运资金量－借款人自有资金－现有流动资金贷款－其他渠道提供的营运资金。

输入逐项追溯本轮原件，记录主体、单体或合并、上年完整年度和测算基准、单位、定义、完整精度与状态。销售利润率的利润分子按适用口径，不擅用净利率、营业利润率或毛利率互代；预计增长来自明确预算、订单、量价及业务结构，目标不当已实现。自有资金构成、各科目日期、可用于周转条件及调整均有依据，用户示例三项加减不形成统一会计定义。现有流贷与其他渠道资金对应余额和用途，零值需证实，区分实际可用与名义授信，保证金及同笔融资不重复扣减。

周转次数可取有来源且口径适用的原始精度值；需自算时按已明确底稿用360÷（存货天数＋应收天数－应付天数＋预付天数－预收天数），说明平均余额及调整方法。收入对应应收预收、成本对应存货预付应付，该360天口径与第三章实际期间指标分开。百分数明确换成比例，用确定性程序保留精度、公式、输入定位、输出及舍入记录；来源有未舍入值时不先舍入重算，只有展示值时注明输入精度限制。分母非正、冲突或缺定义保留不可算状态，不填零、倒推参数或任造增长；负缺口保留数学结果，解释不支持新增需求，不直接等同负额度或批准零额度。

沿用“额度测算核对表”展示原始取值、程序结果、口径来源及状态，并与申请、存量、本次新增、续授信总额、综合及分项、外部结果和建议作同口径桥接。扣除现有流贷是否已含本财务公司存量决定结果身份，不能把保留存量的续作需求再视为全部新增。多个版本保留差异和选择理由，不能选高值覆盖申请。计算或建议更正不覆盖已有批准；封面仍取申请额度。

信用等级评定表按第10.19节固定表头、七项指标及合计等级行，缺已填资料在各格具名披露并保留整表，同时解释已有经营证据。征信与诉讼分别保留实际查询时点、对象和范围，联系融资、担保、历史和当前案件状态；近三年无违约、多平台无记录等结论须有对应覆盖。年度得分不覆盖中期现金恶化。

### 20.3 第八章 授信要素评估

额度核对表与六项要素依据表沿用现有required_assets机制；有资料呈表并解释，无资料保留具名缺口。六项固定小节仍分别形成当前意见，不只列制度清单；第一节按第10.23节，第二至六节按第10.24节展开。

监管附件测算示例为：营运资金量＝上年销售收入×(1－销售利润率)×(1＋预计销售收入增长率)/营运资金周转次数；次数＝360/(存货天数＋应收天数－应付天数＋预付天数－预收天数)；新增流贷＝营运资金量－自有资金－现有流贷－其他渠道营运资金。销售收入对应应收/预收周转，成本对应存货/预付/应付周转。该360天口径不改写第三章按实际期间计算的财务比率。

现按第10.23节使用本轮实际输入完成两步公式，再综合形成额度建议；已有外部底稿逐项核对输入、公式、缓存、文字及结果，保留身份与差异。预测收入联系销量、价格、自产与受托加工、订单和资金承担；月均与期初期末均值、票据/应收融资、合同负债、存货增长或保险系数均有单独依据。自有资金定义不是监管附件给出的统一会计公式；工作簿采用的权益＋长期负债－非流动资产等定义须核对版本、时点、受限和重复资金。

新增缺口、续授信总额、综合授信/分项、集团总额及余额分开。如果扣除项只有外部银行流贷而未扣本财务公司存量，要明确续作口径及重复融资影响；其他渠道资金为零须有依据，并检查公式是否真正引用该项。多个结果不只选覆盖申请的高值，不把公式可算误作政策与业务口径已签认。

期限分别检查：评级一年有效、内部等级期限映射、授信有效期、单笔贷款回款期。监管第十一条的贷款期限原则不超过三年、现金回收周期较长可延长至最长五年，不等于内部AA授信三年的映射，也不授权自动给足上限。评级办法第十八条的更新安排不改写已生效授信期限。监管第二十三条还要求期限超过一年的流动资金贷款，在借贷双方协商基础上原则上本金分期偿还，审慎约定每期还本金额；按适用实施细则核对每期本金与回款，不把多年授信自动写成单笔到期一次还本。

担保检查信用方式资格与按等级需落实的缓释、保证资格能力及抵质押可实现性，高等级不自动免担保。利率检查有效议定方案和定价机制；“按有关规定”不能代替缺失文件。用途按第九、十条核对正常周转，排除股东分红、金融资产/固定资产/股权投资等禁用及实际挪用。第三十条受托支付要求包括新建信贷关系且信用一般、对象明确且单笔支付超过1000万元、贷款人认定的其他情形；适用内部规则和交易支付金额分别核对，不用综合授信总额判断每笔付款。

还款来源分析销售货款的对手方、回收时间、现金归集、可支配性及同期债务；第三十六至三十八条的回笼账户、预警及合作策略评价按实际条件写建议。销售收现不等于经营净现金流，受限存款不等于自由现金，集团支持不等于生效保证。具体核查步骤进批注，实质偿债限制留正文。

### 20.4 第九章 综合结论及回归边界

第九章按第10.25节直接承接第七八章及其底层证据。调查结论归纳经营成果、资金需要、信用状态、现金约束与控制条件，形成有据提请意见；方案按借款人、种类、期限、金额、还款来源、范围及担保七项顺序列明，并补充重要定价、用途和前置条件。维持授信总额不等于净增同额贷款；未审定评级、未选定测算版本、未取得期限映射等须影响对应意见，不能仅藏在批注。

已知依据齐备时形成明确有条件意见，局部未决不把全章写成待补件清单。暂缓或不授信须有实质风险和政策依据；报告的pending_review与业务审批身份不同。评分基础、测算版本、还款现金或条件改变后复核第六至九章。

0.3.3采用配置指纹记录本次细化；新增信用章对前六章的直接依赖，避免经营、财务、行业及风险内容尚未形成就独立下信用结论。写作指引通过现有draft context传递，语义审阅由独立审阅者完成，机械表格/引用检查不证明评分、因果或审批意见成立。江铜华北材料回归、两版本核验、缺口及实际执行范围见[本次回归记录](../../.scratch/financial-credit-policy/qa.md)；具体主体数值不进入通用YAML。

### 21.2 关键口径和条件

股权投资与债权分别呈现，不能加总成坏账；套保损益须匹配现货、期间、实现状态及重复计入，简单加总不自动为真实毛利。保证金对应具体债务、到期及清偿条件，全额到期表与净敞口分列，不能重复扣减。未用授信需考虑共享、品种、保证金、提款与供应商接受条件，未落实续贷不计确定流入。股东背景不自动构成担保或可靠现金支持。

风控条件写对象、基数、目标/限制、期限、责任、检查证据、触发、处置权限、解除条件和剩余风险。区分审批判断阻断、放款前提、贷后约束及普通补件；严禁把关键偿债资料缺失一律延至贷后，或将所有普通补件升级为放款阻断。受托支付结合整体资金流出和回款，冻结新增不替代存量回收。拟议条款未批准或落实时如实标识，无依据不填统一账期、压降幅度或利率。

### 21.3 成文与输出

### 21.4 验收

quality.decision_reviews要求五项独立跨章审阅，criteria来自场景。定位实际正文判断、引用本轮事实/计算并给出assessment。只有章节表格覆盖而缺任何一项决策审阅不得通过；gap须在正文保留相应意见边界，若正文仍无条件支持则needs_changes。

业务验收回答：何种证据和条件下支持；条件不成立如何改变意见；措施落实后仍剩什么风险。程序仅证明覆盖、定位、引用与文件一致，不能证明语义正确、压力假设合理或已获审批。以真实重生成稿另行完成业务与版式验收，不用历史通过记录代替。
