# 预算经营报告排版与交付契约

## 1. 适用范围与权威

预算办快报、月报及按本轮材料规划的板块经营报告共用既有Python核心与CLI。用户明确指定的报告名称、公司、统计期间及正式模板优先；本轮10.5—10.10明确排版值优先于旧样例不一致的字号。场景不预置月份、单位、来源映射或固定章节。旧报告和样例仅为回归与版式参考；所有财务值仍来自本轮已核验统一数据模型。

## 2. 封面与版本

封面独立占第一页，采用简洁居中或正式企业模板，无分析正文。使用Title显示完整报告名称，集中列出核实的当月/累计数据统计期间、实际报告生成日期、分析对象、编制部门、数据性质、报告修订版本、上传数据版本或冻结快照及保密说明。名称与主体不随意改写；标题已含期间时，元信息不得与之冲突。报告统计期间必须核对有效源文件与冻结证据，不取上传批次日期，不将累计期间仅写成当月。

数据版本、经营期间、实际生成日期和报告修订版本各自独立。首版和修订使用可读递增版本（如V1.0→V1.1）；保留系统内部修订ID和快照身份。历史缺少可读版本时明确迁移说明，不能谎称旧文件已有某版本。修订有变更说明，并作为完整新文件保存，不覆盖已发布历史文件。模拟、实际和未知性质明确区分；没有模拟标记不能自动推断为真实。保密等级和措辞依用户授权，未指定则明确待确认，不编造等级。当前矿山原件带MOCK，保留模拟性质和pending_review。

## 3. 统一样式与字体

建立真实Title、Heading 1—3、Normal、Caption、TOC 1—3、表格正文和表格表头样式，继承和覆盖一致；已有Heading 4继续有效。默认封面22磅、一级16、二级14、三级12、正文10.5、表格10、Caption10.5、页眉页脚9、目录10.5磅。中文正文宋体、标题黑体，英文和数字Times New Roman；正式模板统一覆盖时记录依据。不能逐段临时放大或加粗冒充标题。

字体设置覆盖docDefaults、标题、正文、表格、页眉页脚、图注、目录和局部强调，包含w:eastAsia、w:ascii、w:hAnsi，必要时w:cs和中文语言；消除与明确字体冲突的主题继承。核实生成环境实际字体，缺失时使用可靠已安装CJK字体（如Noto/思源或已验证等效字体），记录替代，实际渲染确认无缺字、乱码和严重字宽变化。正文仅有限加粗关键利润、重要风险、结论或必要术语，不无理由整段加粗；不滥用颜色、斜体和下划线，保持正常标点、数字和单位间距。

## 4. 目录

第二页开始独立中文“目录”，目录多页时正常续排，之后第一章独立起页。全部条目来自真实Heading 1—3，保留主模板层级、单位编号与原有顺序，具有实际页码、点引导线和内部跳转，重复小节名称链接到各自章节。目录不能空白、重复、残留已删项或英文Table of Contents。

优先创建TOC \o "1-3" \h \z \u字段并用具备权限的Word或可靠LibreOffice能力实际更新；插入字段或设置打开更新不等于更新完成。若不能可靠更新，则用静态目录，从真实结构提取标题和层级，以最终排版PDF测得页码，多次回排直到目录与正文页码一致，并附内部跳转；不得预测页数或假定每章固定页数。记录采用兜底的环境原因及校验结果。交付门禁验证目录、顺序、层级和每个页码，失败禁止正式交付。

## 5. 正文与章节

目录之后直接进入第一章摘要或本轮主模板首章，不重复封面完整报告总标题。统计期间、版本和性质集中在封面或说明区域，关键业务限制仍在相关分析处披露。章节采用“第一章/1.1/1.1.1”等统一编号；既有单位编号、原名、原顺序与层级保留，不让自动编号改写单位标识。不为全预算场景写死本次九章及六矿。

## 6. 分页与表格

默认A4纵向，统一商务页边距（左右2.3cm、上2.15cm、下2.0cm），正文1.3倍行距和统一分级段间距。封面、目录、第一章独立起页，主要章节另起页；二三级标题、单位标题及表格标题与紧接内容绑定，使用keep_with_next、keep_together、page_break_before、widow_control控制孤行，避免连锁绑定造成一两行独页或大块无谓留白。

财务表格有真正表头和跨页重复表头，采用合适列宽与正文/表头样式；金额右对齐、文本左对齐，重要记录不拆行，允许合理跨页，不溢出正文区域。特别宽的表用局部横向节或附录，不随意将全篇改横向。图表标题不能与对象分离；页码呈现要能与目录核对。

## 7. 图表与单位布局

全部图表有编号、标题、统计期间、单位、来源；模拟数据明确标记。图中文字清楚、字号可读，无方框、缺字、乱码、重叠、图例裁切。高清PNG或兼容对象实际嵌入Word，宽度不超过正文；不能只输出路径。图表数据及计算引用同一本轮已核验模型，不另造数据，表格可编辑。

第四章按本轮模板保留单位标题→经营综述→利润比较表→经营变化文字→生产成本指标表→经营判断和关注事项及本单位可比图。当前矿山回归基准有九章、六矿和独立专项、18张表、7张图，全部内容应保留，允许为规范编号/注记调整呈现而不得篡改数值、来源或正文分析。不设置会删除必要表图的50页上限，不添加凑页内容，通过分页、列宽和图片尺寸改善布局。

## 8. 验收与交付

发布事务在文件生效前检查封面元信息、真实样式/字体、目录页码与结构、分页表格、实际图表及内容保真；可确定排版错误须大声报错并阻止交付，失败不得损坏已发布历史版本。补充针对错误元信息、空/错目录、伪标题、表图缺失/溢出的失败回归。

运行针对性及完整单元测试、report scenarios，重新生成完整DOCX/PDF并逐页审看，以实际文件页码和图像作为证据。记录已执行、失败、跳过、未执行及环境限制，不能将旧抽查当作本轮完整验收。Word 2019+、Microsoft 365及常用WPS为目标兼容环境，仅已实际测试软件可宣称通过；排版通过不替代MOCK性质或业务签认。
