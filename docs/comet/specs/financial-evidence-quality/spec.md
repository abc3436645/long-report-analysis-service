# 财务尽调证据与计算质量契约

## 1. 适用范围与权威

适用于financial_due_diligence的材料归档、冻结、计算、九章起草、独立审阅、校验及发布。报告评价业务公司的经营能力、优势潜力与风险；额度、评级与等级期限关系由现有业务流程提供。固定九章31个二级标题、工商股权表、字体和封面继续由当前场景定义约束。预算及薪酬保持各自契约。

## 2. 材料覆盖与来源

每次运行记录逐份材料用途analysis/context/excluded及理由，不能靠仅上传易读材料隐去原始清单。分析材料须有对应正文事实依据或具名缺口；上下文材料不能悄然作为数值事实。PDF保留物理页数、各页非空文本覆盖及未提取页，不将附注可提取等同报表主表核读完成，也不以无文本推断业务未发生。空页和扫描页仅从文本无法判断时保留待核状态。

OCR、人工核读或转录可提供带原件哈希、衍生物身份、原页/单元格定位及方法的材料；系统不虚构已核验关系。未提供、解析失败、尚未核读、仅部分覆盖、来源冲突分别表达。存在缺口可继续形成完整待复核报告，错算、缺章节和无效引用须修复后才能发布。

## 3. 财务描述计算

计算以当前冻结事实为输入，按主体、报表范围、期间、计量单位及字段身份选择；不把合并附注值当单体，不选择上传顺序解决冲突。来源已给比率与报告复算分别记录身份，避免混算。

注册计算覆盖净利率=净利润/营业收入×100、毛利率=(收入-成本)/收入×100、资产负债率=负债/资产×100、流动比率=流动资产/流动负债、速动比率=(流动资产-存货)/流动负债、应收周转=期间收入/期初期末应收平均余额、存货周转=期间成本/期初期末存货平均余额、ROE=期间净利润/期初期末权益平均余额×100；天数使用明确期间天数除以同期周转次数。180天、实际天数、360/365天或年化必须显式标识，不能推定为业务评级公式。半年年化展示不能冒称真实同比或未年化。

记录公式版本、输入证据ID、期间与基期、单位、年化方式、结果精度及状态。缺分母、缺基期、口径未知、分母为零及冲突时不给猜测值；按适用定义返回状态及受影响判断。金额和比率用Decimal等确定性代码产生。外部流贷测算保留提供结果、版本、定义及未签认身份，双版本并列；配置没有算子不代表用户未提供模型结果，不重建或执行授信模型。

## 4. 起草与数值门禁

财务数值通过当前fact/calc引用提交，来源通过ev定位；在表头已有万元、%、倍、次时，表内数字同样受控。允许结构年份、章节/表格序号等明确数字位置；不能将数字放在表内或改写单位绕过绑定。不通过宽泛删除全部数字实现例外。保留现有固定目录提交及组装校验；基础表有数据则呈现，确无资料时给具名缺口及影响。应用层校验与发布再次核对当前候选，独立渲染仅是版式能力，不产生标准发布回执。

## 5. 内容判断与独立审阅

审阅记录绑定草稿哈希，覆盖31个固定小节和融资章、第二至第五章每张实际表，以及重要优势、风险、缓释和授信要素结论。记录正文定位、相关事实/计算/政策依据、判断及未决事项；遗漏、开放问题、自审或过期哈希不能记录为通过。审阅者ID不同只是必要条件，不能证明真实独立执行，仍需独立于作者的审阅者。

语义判断区分来源解释、分析假设与已验证因果。数项损益加总不自动证明套保有效，负经营净现金流不等于没有销售收现，账面现金扣一项保证金的残差不自动等于可用现金。历史开庭线索、现时未决案件与无执行记录分开；无正式制度不编造授信比例、期限或监测阈值。缺少某项资料只限定相关判断，结论不预设积极或消极；重要事实及冲突同步传至风险、还款来源及综合意见。

## 6. 回归、比较与交付身份

以能触发错误业务判断的合成CLI用例检验输入覆盖、百分比、周转天数、主体/期间冲突、裸表数字、漏表、自审和过期审阅。保留三个场景现有回归，并验证原件及历史交付不变。模型对比保存模型版本、输入及配置哈希、提示、工具权限、调用参数、执行过程、失败和交付链；不齐备则只比较输出，不归因版本优劣。不以模拟调用或单次文件生成冒称真实模型质量验收。
