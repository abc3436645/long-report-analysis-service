## 3. 验收边界

M0 场景加载、M1 预算完整工作稿、M2 四轮修订、M3 三场景与合成检索、M4 三宿主同 wheel 的**脚本化 CLI 运行**已有产物证据。三宿主运行的是固定合成材料和测试规定的正文；尚未证明宿主在开放式任务中自主选择证据、撰写和复核参考报告。`dsh web` 已成功启动本地 Web 服务，但本机计算机控制接口没有可用浏览器，Web UI 中的完整流程未实跑；DeepSeek Harness 的 CLI 回归通过 `dsh headless` 完成。

真实专业服务的认证与 SSE 响应、正式企业预算合并及薪酬人效口径、授信政策与等级期限映射仍待提供和联调。当前合成验收的版本均为 `pending_review`，尚无满足全部业务定义的正式状态样例。预算参考工作稿采用 MOCK 来源，尚未达到四份参考报告的页面与叙事一致性。预算办交付稿为 741 段、152 表，参考为 398 段、101 表；矿山为 167 段、15 表，参考 259 段、12 表；冶炼为 167 段、20 表，参考 233 段、21 表；铜加工为 255 段、38 表，参考 348 段、38 表。结构、单位范围、来源与可比差额已验收，经营成因、专项归属和章节文字仍需业务岗位复核。技术核查记录通过 CLI 审阅接口提交，`reviewer_id` 只是不同于正文作者的记录值，尚未验证真实独立审阅身份。LibreOffice 在本机将交付稿和原参考稿的中文均渲染成方框，故 PDF 转换结果不作为视觉通过证据；macOS Quick Look 缩略图可显示中文标题及目录，尚未逐页完成人工版式检查。

## 4. `0.2.0` 动态规划增量验收
