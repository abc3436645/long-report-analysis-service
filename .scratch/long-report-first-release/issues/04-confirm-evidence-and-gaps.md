# 04: 确认可用证据并记录冲突与缺口

Status: ready-for-agent

**What to build:** 报告编制人可在同一运行中区分候选事实、可用证据、来源冲突、材料缺口和业务定义缺口，再固定供计算和写作使用的证据快照。

**Blocked by:** 03 冻结本轮材料并提交候选事实。

- [ ] 来源、对象、期间和口径检查通过的候选事实才可成为当前范围的可用证据，并保留原始定位。
- [ ] 相互矛盾的来源保留冲突状态；上传先后不会自动裁决真值，明确替代或裁决留痕。
- [ ] 零值、不适用、材料缺口和业务定义缺口分别表示；缺定义仅阻止依赖它的分析。
- [ ] 证据快照固定后，后到事实进入新运行或显式重建，不隐式改变正在写作的依据。
