# 01: 创建报告项目并固定有效配置

Status: ready-for-agent

**What to build:** 报告编制人可通过 CLI 创建、打开报告项目，明确分析场景、对象范围、报告期或评价基准及授信事项，并查看本项目采用的有效配置与业务定义缺口。

**Blocked by:** None (can start immediately).

- [ ] CLI 创建与读取项目返回稳定项目身份、场景版本、对象和时间范围；缺少必需身份信息时明确报错。
- [ ] 仅接受场景声明允许且符合类型、范围的项目覆盖；无效覆盖整体拒绝，不得关闭数值、引用或文件硬检查。
- [ ] 有效配置的来源、版本和指纹可查；新报告期、评价基准或授信事项建立关联项目，不自动复用旧事实。
