# 15: 人力薪酬群体完整报告

Status: ready-for-agent

**What to build:** 薪酬分析人员可按已声明的薪酬口径和群体范围生成完整报告，计算有定义的人效指标，并保护个人及小样本信息。

**Blocked by:** 07 审阅并发布 Markdown/Word 完整版本。

- [ ] 薪酬组成、计量基准、币种、期间及人员范围明确；转岗、兼任和跨期奖金按已声明规则处理。
- [ ] 人效仅在分子、分母、主体与期间可比时计算；缺定义或缺材料时披露缺口，不补造公式。
- [ ] 小样本和交叉表、合计反推按明确规则抑制或合并；规则未定义时不展示受影响数据。
- [ ] 完整 Markdown/DOCX 的正文、表格与资源均不出现个人薪资或个人排名。
