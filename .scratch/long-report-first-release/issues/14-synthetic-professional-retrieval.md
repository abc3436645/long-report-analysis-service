# 14: 合成专业来源检索与授信修订

Status: ready-for-agent

**What to build:** 场景启用外部检索时，报告编制人可通过通用提供者契约取得合成专业记录，核验后形成授信报告新版本；关闭检索的场景不会发起任务。

**Blocked by:** 10 补充材料后的增量修订；13 财务公司授信评审首次完整报告。

- [ ] 合成 HTTP 与 MCP 提供者走相同任务和结果契约，原始响应、状态和来源在证据冻结前归档。
- [ ] 主体、时间和出处核验区分检索线索与可用证据；失败、无结果和部分结果各自披露影响，不推断为低风险。
- [ ] 满足时效和条件时可复用归档结果；条件变化、过期或明确要求时刷新相关任务，单纯措辞改稿不全量重查。
- [ ] 后补专业记录触发可追溯的新报告版本；合成服务通过不宣称真实供应商联调完成。
