# 11: 数据更正、指定章节修改和锁定冲突

Status: ready-for-agent

**What to build:** 报告编制人可明确更正数据或修改指定章节；系统按变更性质更新依赖内容，遇到被锁定的必要变更时要求显式处理冲突。

**Blocked by:** 10 补充材料后的增量修订。

- [ ] 数据更正保留旧值及替代关系，受影响指标、结论和章节进入新完整版本。
- [ ] 纯措辞修改只改变目标章节；其他章节正文和资源身份保持一致。
- [ ] 事实变更必须触及锁定章节时返回可定位冲突，不静默覆盖或绕过锁定。
- [ ] 首次、补件、更正、改章四轮使用同一报告项目，历史版本均可读取。
