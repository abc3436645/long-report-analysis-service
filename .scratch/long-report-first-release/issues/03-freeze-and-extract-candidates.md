# 03: 冻结本轮材料并提交候选事实

Status: ready-for-agent

**What to build:** 主控 Skill 可经 CLI 启动一轮分析，读取固定的材料和配置上下文，领取提取任务并提交带来源定位的候选事实。

**Blocked by:** 02 表格材料入库与定位。

- [ ] 运行记录项目、基础版本、有效配置和本轮材料身份；运行中新增材料不会悄悄改变任务输入。
- [ ] CLI 能列出任务、读取其上下文并提交结果；结果关联任务、输入版本和材料定位。
- [ ] 缺失定位、错误任务身份或过期输入的提交显式拒绝；候选事实不会仅因提交而获得可用证据身份。
