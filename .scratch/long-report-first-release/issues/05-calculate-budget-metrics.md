# 05: 计算预算同口径指标

Status: ready-for-agent

**What to build:** 预算经营分析人员可从已确认依据得到可复核的当月、累计及预算比较结果，且每个结果说明所用预算版本和分析口径。

**Blocked by:** 04 确认可用证据并记录冲突与缺口。

- [ ] 注册算子对人工可核对的合成数据给出预期金额与差异，并保存输入、公式和未舍入结果的溯源。
- [ ] 月度与累计、年度预算与进度预算、集团口径与单位汇总分别检查；不从年度目标臆造月度计划或集团合并值。
- [ ] 错主体、错期间、错预算版本、零分母和缺失输入有明确结果或错误，数值零不当作缺口。
- [ ] 只按场景引用已注册算子；未知算子或参数在运行前拒绝。
