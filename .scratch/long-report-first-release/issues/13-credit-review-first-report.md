# 13: 财务公司授信评审首次完整报告

Status: ready-for-agent

**What to build:** 财务公司评审人员可对指定授信事项、被评审单位和评价基准形成七部分授信风险审查报告，区分证据、风险事项与有条件的策略建议。

**Blocked by:** 07 审阅并发布 Markdown/Word 完整版本；08 文本与 Word 材料入库；09 PDF 材料入库。

- [ ] 以表格、Word 和可解析 PDF 合成材料形成报告，覆盖财务、偿债、担保、诉讼、关联交易、控制及适用的在建项目，并保留事项、主体和时间身份。
- [ ] 检索线索未经核验不成为可用证据；同一风险事项不按材料出现次数重复累计，建议关联依据、条件与待核实项。
- [ ] 已提供的额度、等级、期限分别核对来源和对象；缺少外部结果仍可交付披露缺口的完整待复核版。
- [ ] 报告不运行授信模型、不自行确定授信等级或期限，也不作授信批准决定。
