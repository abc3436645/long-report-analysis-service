# 17: 打包与三宿主验收

Status: ready-for-agent

**What to build:** 验收人员可将同一发行包、主控 Skill 和场景版本交给 Codex、Claude Code、DeepSeek Harness，在三个宿主上经同一 CLI 得到可访问的完整报告。

**Blocked by:** 16 三场景四轮回归。

- [ ] 构建的 wheel 和源码分发包含三个场景及内置模板，在仓库外目录可加载；业务原件、结果和项目工作区不进入发行包。
- [ ] 三宿主使用同一合成材料、场景版本与 CLI 操作序列，记录宿主/模型、包/模板身份、输入哈希和产物位置。
- [ ] 事实、数值、章节覆盖、交付状态与恢复结果满足共同验收标准；措辞差异不作为失败。
- [ ] 验收记录分开报告 M0、工程能力和真实供应商联调状态，不把 Skill 可发现或文件可打开单独当作完整验收。
