# 07: 审阅并发布 Markdown/Word 完整版本

Status: ready-for-agent

**What to build:** 报告编制人可对完整候选报告完成独立审阅、硬检查和 Word 渲染，随后交付具有明确身份的完整报告版本。

**Blocked by:** 06 生成预算完整 Markdown 候选报告。

- [ ] 独立语义审阅与数字、引用、章节覆盖、必需表图和呈现检查可见；错算、坏引用、丢章、损坏文件阻止发布。
- [ ] 交付包含完整 Markdown 和可打开的 DOCX，按场景内置模板呈现可编辑表格、图题与来源信息。
- [ ] 证据不足而硬检查通过时发布披露缺口的待复核版；满足正式门槛时才标正式版。
- [ ] 版本、资源和文件身份固定；验证或导出失败时最近成功交付版本保持不变。
