# 06: 生成预算完整 Markdown 候选报告

Status: ready-for-agent

**What to build:** 主控 Skill 可按场景章节依赖提交预算经营分析的完整 Markdown 候选报告，覆盖全部范围内单位，并让报告读者核对数字、依据和限制。

**Blocked by:** 05 计算预算同口径指标。

- [ ] 候选报告包含所选技术工作稿对应的七个主体部分和每个范围内单位；无数据的单位披露缺口而非被省略。
- [ ] 章节任务使用固定的证据与计算上下文；整体观察和建议在支撑分析之后形成，原因、风险和建议不冒充已证实事实。
- [ ] 关键数字绑定计算结果，事实陈述可定位来源，重要限制同时出现在受影响正文和证据附录。
